# Scripts del pipeline

Els scripts han de ser repetibles des de l'arrel de Maia, amb sortides deterministes i sense sobreescriure registres revisats. El primer que s'implementarà és l'inventari complet de Markdown/frontmatter; després vindran cobertura d'evidència, comprovacions de qualitat, split sense leakage i exportació condicionada a revisió i drets.
