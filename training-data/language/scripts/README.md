# Eines de Maia Language

`build_language_source_audit.py` genera i valida l’informe de procedència, termes d’ús i estat estructural de les transcripcions. Executar des de l’arrel de `maia/`:

```sh
python3 training-data/language/scripts/build_language_source_audit.py --check
python3 training-data/language/scripts/build_language_source_audit.py
```

L’extracció de fragments per a entrenament continua condicionada a la revisió auditiva, la fiabilitat textual i els drets de cada peça.
