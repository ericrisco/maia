# Eines de Language

`build_eligibility_inventory.py` inspecciona tots els documents de `docs/parla/` i separa els filtres del corpus dels drets de cada peça i de la revisió de transcripció.

Executa'l des de l'arrel de `maia/` amb:

```bash
python3 training-data/language/scripts/build_eligibility_inventory.py
```

El recompte és un inventari, no una aprovació d'ús. Cal validar drets i escoltar cada transcripció abans d'afegir fragments a un conjunt d'entrenament.
