# Eines de Language

`build_language_inventory.py` audita totes les peces de `docs/parla/`, desa l'elegibilitat, la procedència, els spans incerts i els torns explícits. Comprova les captures de llicència per vídeo d'AR+I; no estén mai un permís a tota la sèrie. Només conserva intercanvis marcats a la transcripció i valida que els spans coincideixin literalment amb la font. No crea preguntes ni respostes noves.
