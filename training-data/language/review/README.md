# Revisió de Language

Reserva per revisar fragments humans, consentiment aplicable, llicències i
fiabilitat de transcripció. Encara no hi ha registres aprovats.

## Evidència de revisió

Les comprovacions automàtiques es documenten a `docs/raw/parla/<peça>/verification/`.
L'acord entre models ASR és només una pista de revisió: no aprova una transcripció
ni autoritza l'exportació. Cada peça o fragment només es podrà exportar quan
consti una revisió directa de l'àudio i s'hagin resolt o exclòs els trams dubtosos.
