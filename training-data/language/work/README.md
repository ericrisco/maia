# Treball intern de Language

Registra elegibilitat, peça d'origen, parlant si consta, confiança de transcripció, fragments descartats i procedència. Mantén aquests camps fora dels missatges.

`coverage.csv` inventaria les peces actuals de `docs/parla/`; l'elegibilitat del frontmatter és un primer filtre, no una aprovació per exportar. Cal llegir cada peça i verificar-ne la transcripció abans de fer-ne converses.
