# Treball intern de Language

`selection.jsonl` registra totes les entrades de `docs/parla/`, la seva elegibilitat segons `docs/CONTRACT.md`, les fonts i els spans de transcripció incerts. `piece-rights.jsonl` reconcilia els drets de cada peça amb les llicències específiques de vídeo verificades. `authentic-segments.jsonl` conté només spans literalment copiats de peces elegibles, sense reescriptura ni generació. Els fragments encara no estan revisats, dividits ni autoritzats per exportar.

Les particions futures s'han d'agrupar per peça i, quan es pugui, per parlant, per evitar repartir fragments d'una mateixa conversa entre splits.
