# Informes de Language

`eligibility.json` resumeix les 45 entrades inspeccionades, les peces elegibles o excloses, els errors i els drets generals de les fitxes de font. `piece-rights.json` afegeix l'estat de llicència per vídeo quan hi ha metadades verificades. `no-inflation.json` compta els spans autèntics i les línies dubtoses descartades, i confirma que no s'han reescrit ni generat fragments. Encara falten la revisió humana, els permisos pendents i els informes de particions.
