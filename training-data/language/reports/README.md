# Informes Language

`eligibility.json` compta totes les peces, les elegibles, les excloses i les no resoltes. `conversations.json` compta només diàlegs amb torns identificats explícitament. `uncertainty.json` detalla els fragments rebutjats per incertesa i `no-inflation.json` confirma quants fragments són còpia literal. `summary.json` els agrupa amb els estats de drets i la raó per la qual no s'ha generat sortida.
