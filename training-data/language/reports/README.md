# Informes de Maia Language

`eligibility-status.md` resumeix l’auditoria peça per peça de `docs/parla/`. `work/coverage.csv` conserva la decisió, l’estat de transcripció, el perfil del parlant i els drets de cada peça. No s’han generat registres d’entrenament perquè les fonts actuals no proporcionen torns humans de xat amb drets i transcripcions verificats.
