# Informes de Language

`eligibility.json` resumeix les 45 entrades inspeccionades, les peces elegibles o excloses, els errors i les fonts. `no-inflation.json` compta els spans autèntics i les línies dubtoses descartades, i confirma que no s'han reescrit ni generat fragments. Encara falten la revisió humana, els drets i els informes de particions.
