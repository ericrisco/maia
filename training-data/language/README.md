# Maia Language

Espai separat per a material lingüístic humà de `maia/docs/parla/`. No generem exemples sintètics de «com parlaria un andorrà».

Abans d'incloure fragments, cal verificar-ne la transcripció, les condicions d'ús i la procedència. Les peces dubtoses s'han de filtrar o marcar; no s'han de convertir silenciosament en senyal lingüística.

`work/coverage.csv` enumera les peces Markdown de `docs/parla/`. El seu estat inicial és pendent; s'actualitzarà només després de revisar cada peça i les seves condicions d'ús.
