# Maia Language

Conjunt separat per conservar el català andorrà contemporani de persones reals. Només s'hi incorporaran fragments amb drets, consentiment i transcripció verificats. No es generaran respostes per imitar una veu local.

L’estat de llicències, la qualitat estructural de les transcripcions i les comprovacions pendents es resumeixen a [l’auditoria de fonts](reports/source-audit.md). Les mostres amb llicència oberta continuen sent candidates fins a completar la revisió auditiva i contextual.
