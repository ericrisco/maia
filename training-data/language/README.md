# Maia Language

Dataset separat per preservar parla humana autèntica en català andorrà contemporani, a partir de material elegible de `docs/parla/`.

Aquí no es generen diàlegs de mostra amb respostes inventades: això contaminaria el senyal lingüístic. `examples/` queda reservat a exemples de format clarament etiquetats si en calen. `review/` contindrà fragments humans candidats amb procedència. `work/` documentarà elegibilitat i verificació; `output/` només contindrà fragments humans revisats i amb drets compatibles.
