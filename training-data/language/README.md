# Maia Language

Via separada per a català andorrà contemporani produït per persones, a partir de `docs/parla/` i dels seus criteris d'elegibilitat. Preservar les paraules i la forma oral de la font. No redactar respostes noves per imitar una veu andorrana.

Abans de preparar registres, comprovar torns identificables, fiabilitat de transcripció, permisos i agrupació per peça o parlant. Aquesta carpeta és només l'esquelet; encara no hi ha mostres aptes per exportar.
