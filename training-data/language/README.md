# Maia Language

Objectiu separat de Knowledge: conservar el català andorrà contemporani produït
per persones, a partir de material elegible de `docs/parla/`. No s'inventen
preguntes per convertir monòlegs en diàlegs ni es reescriu la parla humana per
fer-la semblar més andorrana.

Cada peça s'haurà de revisar quant a veu, època, `apte_llengua`, fiabilitat de la
transcripció i drets. Les respostes només es poden extreure de torns humans
identificables. Ara no hi ha exemples ni exports.
