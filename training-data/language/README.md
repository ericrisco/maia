# Maia Language

Objectiu separat de Knowledge: preservar català andorrà contemporani produït per parlants reals a `docs/parla/`.

No s'inventaran preguntes i respostes per simular com parla una persona andorrana. Els camps `veu`, `epoca` i `apte_llengua` del corpus són un prefiltre necessari. Abans d'incloure cada peça, també cal verificar que el parlant usa català andorrà contemporani, contrastar la transcripció amb l'àudio i confirmar els drets per a aquella peça concreta.

Si una peça parla d'Andorra però no permet establir la procedència lingüística del parlant, no s'etiqueta automàticament com a parla andorrana. Es conserva com a pendent o s'exclou segons l'evidència. No es creen diàlegs ficticis a partir de monòlegs.

Encara no hi ha exemples ni exports.
