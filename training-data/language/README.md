# Maia Language

Via separada per a català andorrà contemporani produït per persones, a partir de `docs/parla/` i dels seus criteris d'elegibilitat. Preservar les paraules i la forma oral de la font. No redactar respostes noves per imitar una veu andorrana.

Abans de preparar registres, comprovar torns identificables, fiabilitat de transcripció, permisos i agrupació per peça o parlant. Executa `python3 training-data/scripts/build_language_review.py` des de l'arrel de Maia per regenerar l'auditoria. No es crea cap conversa a partir d'una narració sense torns explícits.
