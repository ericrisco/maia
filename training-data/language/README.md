# Maia Language

Objectiu separat de Knowledge: preservar català andorrà contemporani produït per parlants reals a `docs/parla/`.

No s'inventaran preguntes i respostes per simular com parla una persona andorrana. Només s'hi incorporarà material humà que compleixi els criteris de veu, època i aptitud del corpus, amb transcripció prou verificada i drets documentats. Encara no hi ha exemples ni exports.
