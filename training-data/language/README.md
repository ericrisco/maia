# Maia Language

Conjunt separat per conservar català andorrà contemporani produït per persones, a partir de `docs/parla/`. No s'hi redacten respostes noves per imitar una persona ni es creen preguntes fictícies per a monòlegs.

- `examples/`: fragments de calibratge només quan n'hi hagi de verificats i elegibles.
- `review/`: decisions de selecció i revisió de fragments.
- `work/`: parlant, transcripció, drets i procedència.
- `reports/`: inclusions, exclusions i qualitat.
- `output/`: buit fins a l'aprovació, deduplicació i splits.

Primer cal revisar cada peça per parlant original, llengua, fiabilitat de transcripció i drets. El permís s'audita per peça de vídeo; una llicència d'una càpsula no s'estén a tota la sèrie. Agrupar els splits per peça o parlant per evitar filtracions.

Inventari actual: 45 fitxes Markdown, 40 peces de parla, 38 elegibles per veu i `apte_llengua`, 2 excloses i cap pendent de classificació. Les altres 5 fitxes són índexs o síntesis, no mostres de parla. Hi ha 10.510 fragments literals, però **cap parella explícita d'entrevistador i parlant**. Els drets de les 27 entrevistes del Consell General i de 7 càpsules elegibles d'AR+I continuen pendents; quatre càpsules elegibles tenen una llicència CC BY confirmada per peça. Cap fragment no és exportable mentre falti una conversa real, transcripció prou verificada i permís aplicable.
