# Maia Training Data

Àrea de treball per preparar dos fluxos independents:

- **Knowledge**: respostes informatives fonamentades en `docs/temes/`.
- **Language**: mostres reals de català andorrà de `docs/parla/`.

No es barregen objectius ni registres. Knowledge té 54 converses aprovades per
cobertura i procedència, però la revisió de naturalitat s'ha reobert i la
cobertura és parcial. Encara no s'han generat exports d'entrenament. Language
té l'inventari de fonts, però cap peça no ha superat encara la revisió
necessària per exportar-la.

El procés i els criteris són a [`PLAN.md`](PLAN.md). Les mostres inicials i els
criteris de conversa són a [`knowledge/review/EXEMPLES.md`](knowledge/review/EXEMPLES.md).
