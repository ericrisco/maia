# Maia Training Data

Àrea de treball per preparar dos fluxos independents:

- **Knowledge**: respostes informatives fonamentades en `docs/temes/`.
- **Language**: mostres reals de català andorrà de `docs/parla/`.

No es barregen objectius ni registres. El calibratge de Knowledge s'ha reiniciat
amb tres mostres. No són dades d'entrenament aprovades. La cobertura continua
parcial i encara no hi ha exports. Language té un inventari de fonts, però cap
peça no ha superat la revisió necessària per exportar-la.

El procés i els criteris són a [`PLAN.md`](PLAN.md). Les mostres de calibratge
i la guia de naturalitat són a
[`knowledge/review/EXEMPLES.md`](knowledge/review/EXEMPLES.md).
