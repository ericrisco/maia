# Maia Training Data

Àrea de treball per preparar dos conjunts separats:

- **Maia Knowledge**: ensenyar coneixement sobre Andorra a partir de `docs/temes/` amb preguntes que una persona faria de debò.
- **Maia Language**: conservar llengua humana autèntica de `docs/parla/`, sense inventar-hi preguntes ni respostes.

Ara hi ha una mostra nova de calibratge i una cua de revisió buida. El primer esborrany s’ha arxivat perquè no es confongui amb material aprovat. Els exports són buits: encara no hi ha cap dataset d’entrenament.

Consulta [PLAN.md](PLAN.md) per al mètode i [knowledge/review/EXEMPLES.md](knowledge/review/EXEMPLES.md) per als criteris i exemples de conversa. Els exemples de calibratge no s’exporten.
