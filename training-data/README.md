# Maia Training Data

Àrea de preparació de dos conjunts separats. **Knowledge** ensenya a respondre preguntes sobre Andorra a partir del corpus; **Language** conserva formes reals del català andorrà contemporani.

Estat actual: `knowledge/review/` conté 19 converses revisades, però només cobreixen societat, demografia i habitatge/tabac de manera parcial; no representen encara tot el corpus. No hi ha cap export d'entrenament. Els exemples de calibratge serveixen per acordar el to i no es compten com a cobertura. `language/` encara no té cap fragment aprovat per exportar; el corpus de parla conserva candidats pendents de revisió auditiva i de drets.
