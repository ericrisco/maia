# Maia Training Data

Aquest espai prepara dues fonts d'aprenentatge separades:

- [**Knowledge**](knowledge/README.md): converses útils sobre Andorra, basades
  en el corpus `docs/temes/`.
- [**Language**](language/README.md): català andorrà contemporani extret de
  parla humana elegible a `docs/parla/`.

El [pla](PLAN.md) defineix com crear i revisar les converses. Els exemples de
[Knowledge](knowledge/examples/EXEMPLES.md) són només una guia d'estil. No són
dades d'entrenament i no s'exporten.

Els registres Knowledge existents s'han de revalidar un per un amb els criteris
actuals. El fet que ja siguin a `review/` no vol dir que estiguin aprovats. No
hi ha cap exportació Knowledge final. Language manté el seu flux i les seves
fonts separades.
