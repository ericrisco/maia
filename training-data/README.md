# Maia Training Data

Aquest directori prepara dos conjunts separats a partir de `docs/`:

- **Knowledge**: respostes útils sobre Andorra, basades en fets del corpus.
- **Language**: català andorrà contemporani extret de parla humana elegible.

Les mostres editorials de [`knowledge/review/EXEMPLES.md`](knowledge/review/EXEMPLES.md)
serveixen per calibrar l'estil i no són registres d'entrenament. `review/` conté
converses candidates i la seva procedència. Els fitxers finals de `output/` es
crearan quan s'hagin revisat els drets, la qualitat, la cobertura i la separació
entre conjunts.

Comenceu per [`PLAN.md`](PLAN.md) i les [mostres de Knowledge](knowledge/review/EXEMPLES.md).
