# Maia Training Data

Aquest espai prepara dues dades d'entrenament amb objectius diferents:

- **Maia Knowledge**: respostes útils sobre Andorra, basades en `docs/temes/`.
- **Maia Language**: ús del català andorrà contemporani, a partir de parla humana de `docs/parla/`.

Comencem per acordar com sona una conversa de Knowledge. Les set mostres a `knowledge/examples/` són material de revisió, no dades d'entrenament. Les preguntes parteixen d'un dubte humà, les respostes el resolen al primer torn i els seguiments només continuen el fil. La procedència i els drets consten en un fitxer separat.

El pla descriu les fases següents. No hi ha exports d'entrenament encara.
