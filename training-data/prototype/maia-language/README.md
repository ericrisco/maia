# Maia Language

Dataset separado para aprender formas reales del catalán andorrano. Se nutre
solo de material elegible de `docs/parla/`; no se generan respuestas
enciclopédicas con voz inventada.

- `review/`: fragmentos humanos verificados y sus datos de procedencia.
- `output/`: exportaciones regenerables para entrenamiento.
- `reports/`: inclusión, exclusión y controles de calidad.
