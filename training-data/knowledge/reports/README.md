# Informes Knowledge

`inventory.json` resumeix la lectura inicial. `coverage-summary.json` mostra quantes unitats d'evidència tenen un esborrany, quantes tenen conversa aprovada, quines continuen pendents i com es reparteixen per tema. El ledger detallat per unitat es regenera a `coverage.json`.

Executa `python3 training-data/scripts/build_knowledge_coverage.py` des de l'arrel de Maia per refrescar la reconciliació. Una xifra de cobertura no substitueix la revisió de naturalitat ni l'autorització de drets.
