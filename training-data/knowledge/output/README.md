# Export de Maia Knowledge

Encara no hi ha fitxers finals. Aquí només entraran converses aprovades, deduplicades i amb procedència revisada. Cada línia final contindrà únicament `messages`.

Els splits `train`, `validation` i `test` es crearan quan hi hagi prou dades revisades i es puguin agrupar per coneixement compartit per evitar que variants gairebé idèntiques quedin repartides entre splits.
