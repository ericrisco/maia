# Maia Knowledge

Converses informatives basades en `docs/temes/`. La naturalitat de cada diàleg i
la cobertura del corpus es revisen per separat.

- `review/`: registres revisats amb conversa i procedència a la mateixa línia;
  `conversations.jsonl` és l'export de missatges aprovats.
- `work/`: inventaris i decisions de cobertura regenerables.
- `reports/`: informes de cobertura, exclusions i qualitat.
- `scripts/`: inventari, validador i proves dels dos processos.
- `output/`: exports train, validation i test, després de revisar cobertura,
  drets i separació per grup.
