# Maia Knowledge

Converses en català que responen dubtes reals sobre Andorra. La font factual és `docs/temes/`. La procedència i els drets queden separats dels missatges.

Les mostres de [`examples/`](examples/) són una guia editorial, no un dataset entrenable. La primera tanda rebutjada es conserva a [`archive/rejected-v1/`](archive/rejected-v1/). La cua de [`review/`](review/) parteix de zero i espera converses noves amb comprovació humana. Els exports de [`output/`](output/) romanen buits fins a l’aprovació de contingut i drets.
