# Maia Knowledge

Converses sobre Andorra basades en `docs/temes/`.

- `examples/conversations.jsonl`: quatre mostres multitorn per calibrar naturalitat i qualitat de resposta.
- `examples/provenance.jsonl`: fonts, afirmacions, límits i situació dels drets de les mostres.
- `review/GUIA.md` i `review/EXEMPLES.md`: criteris editorials i procés de revisió.
- `review/conversations.jsonl`: converses candidates, encara no aprovades.
- `review/provenance.jsonl`: fonts, afirmacions, límits i drets dels candidats.
- `work/coverage.csv`: inventari de tots els documents de `docs/temes/` i estat de cobertura.
- `output/README.md`: condicions per crear exports futurs.

Les converses d'exemple no són un dataset d'entrenament. No s'exporta cap font mentre els drets no estiguin revisats.
