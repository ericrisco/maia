# Maia Knowledge

Conjunt de converses informatives sobre Andorra basades principalment en `docs/temes/`. Cada registre que es vulgui entrenar ha de respondre un dubte humà, tenir evidència verificable i provenir de fonts reutilitzables.

`review/EXEMPLES.md` fixa el criteri de redacció. Són mostres editorials, no registres aprovats. `review/` és per a revisió i procedència; `output/` serà només per als exports nets amb `messages`.
