# Maia Knowledge

Converses en català que ajuden a entendre Andorra. Els fets s'han de poder justificar amb `docs/temes/`; les preguntes han de sonar com dubtes humans, no com instruccions per recuperar dades d'una pàgina.

- [`examples/`](examples/): cinc mostres editorials amb preguntes contextualitzades i seguiments naturals. No són candidats d'entrenament.
- [`review/`](review/): cua neta per als pròxims registres, encara buida i pendent d'aprovació humana.
- [`archive/`](archive/): versions rebutjades. No compten per cobertura ni poden entrar als exports.
- [`work/`](work/): inventari i evidència traçables.
- [`reports/`](reports/): cobertura i controls.
- [`output/`](output/): s'omple només quan contingut i drets han estat aprovats.

La procedència és separada dels missatges. Una mostra d'estil no es converteix en candidata només perquè sembli bona.
