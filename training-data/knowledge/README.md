# Maia Knowledge

Dataset de converses sobre Andorra basades en `docs/temes/`.

- `examples/conversations.jsonl`: quatre mostres de calibració; no són dades aprovades per entrenar.
- `examples/provenance.jsonl`: fonts, afirmacions, límits de les fonts i estat dels drets de cada mostra.
- `work/coverage.csv`: inventari de documents i progrés de cobertura.
- `reports/parser-coverage.md`: resum dels documents, seccions, taules, files, enllaços i errors llegits pel parser.
- `output/`: exports futurs, només després de revisió i aprovació de drets.

Una conversa ha de resoldre una curiositat real i contenir seguiments coherents. No preguntem per fitxes ni seccions. Consulteu `../PLAN.md` abans de crear registres.
