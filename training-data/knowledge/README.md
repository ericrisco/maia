# Maia Knowledge

## Carpeta de calibratge

`calibration/` conté exemples de referència per ensenyar l'estil de pregunta i
resposta. No són automàticament aptes per entrenar ni s'inclouen en cap export.
Cada exemple necessita una revisió pròpia de contingut, procedència i drets
abans de poder passar a `review/`.

Ensenya a respondre preguntes útils sobre Andorra a partir de `docs/temes/`.

## Carpetes

- `examples/`: cinc mostres internes per calibrar naturalitat i continuïtat.
- `review/`: es manté buit fins que l'usuari aprovi el criteri; després acollirà candidats nous.
- `archive/`: motius de rebuig o retirada, si n'hi ha.
- `work/`: notes de cobertura i procedència per a les tandes futures.
- `reports/`: informes de qualitat i cobertura.
- `output/`: buit fins que les converses i els drets estiguin aprovats.

Els exemples actuals són només per a revisió. No s'han d'entrenar ni exportar. Llegiu també [la guia de conversa](examples/README.md).
