# Les set parròquies — índex territorial

L'índex organitza aquesta branca en set subbranques locals: [Andorra la Vella](./andorra-la-vella-index.md), [Canillo](./canillo-index.md), [Encamp](./encamp-index.md), [Escaldes-Engordany](./escaldes-engordany-index.md), [La Massana](./la-massana-index.md), [Ordino](./ordino-index.md) i [Sant Julià de Lòria](./sant-julia-de-loria-index.md). La veu per defecte que declara és `compilada`.

La descripció de la font presenta festes, danses i toponímia com a temes propis de les parròquies. Aquest índex és un mapa editorial: no verifica per si sol que cada tema tingui una font entrenable ni que cada parròquia disposi de la mateixa cobertura.

Les set fitxes article vinculades han estat auditades i disposen de versions netes a [Andorra la Vella](./andorra-la-vella.md), [Canillo](./canillo.md), [Encamp](./encamp.md), [Escaldes-Engordany](./escaldes-engordany.md), [La Massana](./la-massana.md), [Ordino](./ordino.md) i [Sant Julià de Lòria](./sant-julia-de-loria.md). Cadascuna d'aquestes fonts locals conté un article. Els set índexs locals encara no tenen tots una còpia neta; només Ordino n'ha estat processat. Les rutes dels altres sis índexs són estables i pendents de la seva pròpia revisió.

Les descripcions dels índexs locals anomenen cada parròquia segons una numeració «protocol·lària». Les fitxes netes només tracten aquesta numeració com l'ordre d'enumeració de l'article 1.5 de la Constitució, sense inferir-ne una regla general de precedència.
