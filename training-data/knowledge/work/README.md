# Treball de Knowledge

Conté l'inventari de documents, unitats d'evidència, relacions i el registre de
cobertura regenerats des de `docs/`. `manual-unit-exclusions.jsonl` recull
exclusions revisades amb un motiu concret; no l'editis a mà per descartar dades
només perquè encara no tenen una conversa. Després de canviar-lo, torna a
executar el lector d'inventari indicat a `../scripts/README.md`.
