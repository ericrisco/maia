# Material de treball

`coverage.csv` enumera totes les fitxes de `docs/temes/`. Totes comencen pendents; els índexs també s'han de revisar per si contenen coneixement propi. La cobertura fina s'ha de desglossar per afirmació, taula, data, excepció i límit abans de donar una fitxa per coberta.

El material intern de treball no s'inclou a les converses d'export. Cada afirmació coberta ha d'enllaçar amb una conversa i les seves fonts.

`coverage-items.jsonl` registra les unitats factuals ja vinculades a candidates; una fitxa només passa a `covered` quan totes les unitats útils han estat revisades i cobertes. Una candidate bloquejada per font o drets compta com a representació provisional, no com a cobertura exportable.
