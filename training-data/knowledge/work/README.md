# Treball intern de Knowledge

Inventari de documents, cobertura, fonts, hashes, llicències i notes de revisió. Aquesta informació no entra dins dels missatges del model.

`coverage.csv` inventaria tots els documents de `docs/temes/`. Els estats `candidate_pending_review` i `pending_review` no compten com a cobertura aprovada. `coverage-items.jsonl` conserva unitats candidates que s'han de tornar a comprovar contra la font. Vegeu l'estat resumit a [coverage.md](../reports/coverage.md).
