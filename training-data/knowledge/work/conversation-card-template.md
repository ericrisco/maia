# Targeta per preparar una conversa

Duplica aquesta targeta per a cada conversa candidata. No la copiïs al dataset
final.

## Intenció

- Què vol aclarir una persona?
- Per què li podria sorgir aquest dubte?
- Quina pregunta faria sense haver vist les fitxes?

## Evidència

- Fets exactes que responen el dubte:
- Fonts de Maia que sostenen cada fet:
- Llicència i condicions de reutilització:
- Què no consta o no es pot concloure:

## Fil de la conversa

1. Pregunta inicial:
2. Resposta directa:
3. Quina idea de la resposta pot fer néixer un seguiment?
4. Seguiment:
5. Resposta al seguiment:
6. Cal un altre intercanvi? Quin dubte nou resoldria?

## Lectura editorial

- S'entén sense obrir les fonts? Sí / No
- Cada seguiment reprèn el torn anterior? Sí / No
- Respostes completes i sense dades deslligades? Sí / No
- Hi ha context inventat o afirmacions no sostingudes? Sí / No
- Hi ha un registre aprovat amb la mateixa intenció? Sí / No
- Puntuació (intenció, naturalitat, fil, resposta, fidelitat), 0–2 cadascun:
- Decisió: reescriure / rebutjar / enviar a revisió de procedència i drets
