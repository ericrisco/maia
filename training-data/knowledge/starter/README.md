# Pilot de Maia Knowledge

Aquest directori conté quatre exemples per calibrar el tipus de conversa que
volem. Són una mostra petita, no una afirmació de cobertura. Cada línia de
`conversations.jsonl` és una conversa en format de missatges; `provenance.jsonl`
relaciona l'exemple amb les fitxes i l'estat de drets.

El corpus antic continua separat a `../review/` i `../output/`. Durant el pilot,
no s'hi incorporen exemples nous ni es presenten les exportacions antigues com
un dataset aprovat amb el criteri nou.
