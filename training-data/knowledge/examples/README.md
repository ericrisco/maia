# Mostres de converses

`conversations.jsonl` conté tres mostres multitorn per calibrar preguntes, respostes i continuïtat. `provenance.jsonl` conté la procedència alineada per línia.

Són exemples de disseny, no dades aprovades ni exportables. No compten com a cobertura i no s'han d'entrenar. El criteri de revisió és a [`../review/EXEMPLES.md`](../review/EXEMPLES.md).
