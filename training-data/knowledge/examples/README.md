# Mostres de calibratge

`conversations.jsonl` conté cinc diàlegs de treball per valorar si les preguntes sonen humanes i si els seguiments aporten informació nova. No són un export d'entrenament ni una afirmació que el corpus ja estigui cobert. La procedència i els drets es revisen abans de qualsevol aprovació.

Llegeix primer només els missatges. Després contrasta cada afirmació amb les rutes de font de `knowledge/work/provenance.jsonl`.
