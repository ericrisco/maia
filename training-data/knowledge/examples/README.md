# Mostres de converses

`conversations.jsonl` conté cinc mostres multitorn per calibrar preguntes, respostes i continuïtat. `provenance.jsonl` conté la procedència per exemple.

Són exemples de disseny, no dades aprovades ni exportables. No compten com a cobertura i no s'han d'entrenar. El criteri de revisió és a [`../review/EXEMPLES.md`](../review/EXEMPLES.md).

Les carpetes `output/` continuen buides perquè encara no hi ha registres aprovats per contingut i drets. Les mostres serveixen per acordar com han de sonar els diàlegs; no s'han de confondre amb els datasets finals.
