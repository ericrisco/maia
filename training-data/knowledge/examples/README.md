# Exemples de calibratge

Les cinc converses de `conversations.jsonl` mostren preguntes inicials que s'entenen sense la font, respostes directes i seguiments lligats al torn anterior. Llegeix-les en veu alta i sense obrir les fitxes.

Són exemples editorials, no registres aprovats, no compten per a cobertura i no s'exporten. La traçabilitat i els límits de cada mostra consten a `provenance.jsonl`. Si una pregunta sona escrita només per cobrir una dada, cal reescriure-la abans de crear més registres.
