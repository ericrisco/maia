# Exemples de calibratge

`conversations.jsonl` mostra l'estil de diàleg desitjat. `provenance.jsonl` en registra els documents de suport i l'estat de revisió. Aquests exemples serveixen per discutir i calibrar l'estil; no són exemples aprovats per entrenar ni s'han de copiar automàticament a `review/` o `output/`.
