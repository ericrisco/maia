# Calibratge de Maia Knowledge

`conversations.jsonl` conté quatre exemples per acordar naturalitat, seguiments i límits de resposta. No són registres aprovats i mai no passen directament a l'entrenament. `provenance.jsonl` en documenta les fonts i l'ús previst, línia per línia.

Llegeix les converses sense obrir les fonts. Si la pregunta sembla un exercici sobre una fitxa o si el seguiment no surt de la resposta, cal revisar el criteri abans de reprendre la cua.
