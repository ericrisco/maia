# Exemples editorials de Knowledge

Els exemples mostren el to i el tipus de seguiment que busquem. No són
registres, no compten per a la cobertura i no s'han d'afegir a cap exportació.

Abans d'afegir una conversa nova, llegiu [EXEMPLES.md](EXEMPLES.md) i
[el pla general](../../PLAN.md). Cada pregunta ha de tenir sentit per si sola
amb el context acumulat de la conversa. Cada resposta ha de resoldre aquella
pregunta.
