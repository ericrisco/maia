# Calibratge de Knowledge

`CONVERSATION-GUIDE.md` és la guia editorial i conté els exemples de referència.
`EXEMPLES.md` hi apunta per mantenir un únic criteri. `conversations.jsonl`
conté les converses candidates, una per línia. `provenance.jsonl` registra les
fonts i l'estat de drets i revisió de cada conversa.

Per cada conversa, llegiu el fil sense consultar les fonts i després comproveu
cadascuna de les afirmacions amb les fonts. Apliqueu la llista de control de la
guia. No exporteu un registre sense procedència i revisió editorial.
