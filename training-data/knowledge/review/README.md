# Revisió de Maia Knowledge

Aquest espai s’ha reiniciat i ara no conté candidats. Els registres antics s’han retirat de l’àrea activa perquè les preguntes no seguien el criteri de naturalitat. Els candidats nous només hi entraran després de tenir una conversa natural i una procedència traçable. Cada registre pendent s'ha de revisar pel contingut, la naturalitat, la cobertura i els drets. No es compta ni s'exporta com a dada aprovada.
