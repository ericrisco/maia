# Calibratge de Knowledge

`EXEMPLES.md` és la guia editorial. `conversations.jsonl` conté les converses
que es revisen per al dataset, una per línia. `provenance.jsonl` registra les
fonts i l'estat de drets i revisió de cada conversa.

Per cada conversa, llegiu el fil sense consultar les fonts i després comproveu
cadascuna de les afirmacions amb les fonts. No exporteu un registre sense
procedència i revisió editorial.
