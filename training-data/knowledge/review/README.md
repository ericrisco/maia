# Revisió de Maia Knowledge

`conversations.jsonl` conté converses candidates de Knowledge, una conversa completa per línia. `provenance.jsonl` en registra les fonts, les unitats d'evidència, els drets, l'estat de revisió i el hash de cada línia. Les candidates no compten com a coneixement aprovat ni s'exporten fins que passen les revisions editorial, factual i de drets previstes al `PLAN.md`.

`EXEMPLES.md` compara preguntes de fitxa amb diàlegs més naturals. `quarantine/` conserva els lots antics només per a consulta; no els copiïs a les mostres noves sense revisar cada conversa des del principi.
