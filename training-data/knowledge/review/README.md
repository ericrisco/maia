# Revisió de Maia Knowledge

`conversations.jsonl` conté converses candidates de Knowledge, una conversa completa per línia. `provenance.jsonl` en registra les fonts, les unitats d'evidència, els drets, l'estat de revisió i el hash de cada línia. Ara mateix són buits: `EXEMPLES.md` només fixa l'estil i no forma part del lot. Les candidates no compten com a coneixement aprovat ni s'exporten fins que passen les revisions editorial, factual i de drets previstes al `PLAN.md`.

`EXEMPLES.md` conté dues mostres editorials per acordar l'estil. `quarantine/` conserva els lots antics només per a consulta; no els copiïs a les mostres noves sense revisar cada conversa des del principi.
