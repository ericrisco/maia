# Revisió de Maia Knowledge

- `CONVERSATION-GUIDE.md`: criteris per redactar i revisar un fil.
- `EXEMPLES.md`: exemples de calibratge; no s'entrenen ni compten com a registres.
- `conversations.jsonl`: cua de candidats; buida al començament.
- `provenance.jsonl`: procedència dels candidats; buida al començament.
- `examples-provenance.md`: fonts i límits dels exemples editorials.

Una línia de conversa conté només `messages` amb rols `user` i `assistant`. Una línia corresponent de procedència guarda la informació de revisió fora del text que rebria el model.
