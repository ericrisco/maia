# Revisió de Maia Knowledge

- `examples.jsonl`: mostres de calibratge; excloses de qualsevol export.
- `evidence.jsonl`: procedència, afirmacions i drets de les mostres editorials.
- `conversations.jsonl`: candidates en format de conversa, sense metadades internes.
- `records.jsonl`: una entrada per conversa amb estat de revisió, fonts, drets i unitats de coneixement cobertes.

No afegiu registres només perquè una fitxa tingui una secció o una fila de taula. Llegiu cada conversa sencera i reviseu els criteris de `../../PLAN.md`.
