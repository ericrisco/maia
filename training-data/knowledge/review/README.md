# Revisió de Maia Knowledge

`conversations.jsonl` conté registres acumulats encara no aprovats.
`pilot.jsonl` conté quatre exemples nous per provar l'estàndard editorial.
`pilot-provenance.jsonl` conté fonts, evidència i estat dels drets del pilot.
`EXEMPLES.md` defineix com acceptar, reescriure o rebutjar cada diàleg.

Cap conversa no passa a `output/` sense revisió de contingut, naturalitat i
drets. Els exemples amb drets pendents o incompatibles serveixen només per
discutir l'edició.
