# Revisió de Knowledge

Cada línia de `conversations.jsonl` és una conversa candidata amb missatges `user` i `assistant` alternats. `provenance.jsonl` conté una fila corresponent amb les fonts, les notes de verificació i l'estat dels drets. Els candidats continuen pendents de revisió humana i no són exports entrenables.

Abans d'aprovar: pregunta humana, seguiments naturals, resposta directa, afirmacions verificades, incertesa preservada i cap dada interna dins dels missatges. Les mostres de `../examples/` són el patró editorial, no un substitut de la revisió.
