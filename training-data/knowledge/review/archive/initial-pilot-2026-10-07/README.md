# Pilot anterior: arxivat

El pilot de 18 converses s'ha retirat de la cua activa perquè les preguntes depenien massa de fitxes, apartats i dades internes. Es conserva aquí per poder revisar-ne les afirmacions i la procedència sense confondre'l amb el pilot nou.

- `conversations.jsonl`: les 18 converses candidates antigues.
- `provenance.jsonl`: la procedència i les notes editorials corresponents.
- `document-status.json`: l'estat de revisió anterior al reinici del calibratge.

Cap d'aquests fitxers és un conjunt aprovat. No s'han d'exportar ni de comptar com a cobertura activa. Les converses futures han de passar el filtre de `../../CONVERSATION-GUIDE.md`.
