# Quarantena editorial

Els fitxers `batch-before-human-redesign-*` conserven un lot antic de 53 converses. `before-human-intent-redesign-20261007/` conserva les 10 converses que eren actives abans del redisseny d'estil. Les mostres dels pilots anteriors també es conserven aquí.

Aquest material no és aprovat ni exportable. No el reincorporis per inèrcia. Reescriu cada candidat segons els criteris nous i comprova de nou la resposta, l'evidència, els drets i la hash.
