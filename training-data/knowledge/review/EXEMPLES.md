# Exemples de calibratge

Els tres diàlegs revisables són a [`calibration.jsonl`](calibration.jsonl). Són mostres editorials, no candidats ni dades d'entrenament. La seva procedència i els límits de cada resposta consten a [`procedencia-exemples.md`](procedencia-exemples.md).

## Què mostren

1. Un dubte real sobre quan un tractat s'aplica i quan entra formalment en vigor.
2. Una pregunta que comprova si una obligació de consulta equival a una intervenció garantida.
3. Una lectura prudent d'una comparació estadística amb només dos anys observats.

Cada conversa comença amb una pregunta autònoma. Els seguiments reprenen el torn anterior i afegeixen una precisió nova. Les respostes contesten directament i no exposen la font interna.
