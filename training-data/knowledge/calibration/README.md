# Converses de calibratge

Aquests exemples serveixen per revisar si una conversa sona humana i contesta
el dubte. No s'exporten ni s'incorporen al dataset automàticament. La
procedència és aquí perquè cada resposta es pugui comprovar. Els drets de cada
font s'han de resoldre abans de reutilitzar-ne el contingut en un dataset.

La mostra inclou preguntes contextualitzades, respostes directes i seguiments
que surten del torn anterior. Si una dada no permet una continuació natural,
no s'ha d'afegir cap torn només per allargar la conversa.
