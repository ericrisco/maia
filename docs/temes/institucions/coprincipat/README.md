# El Coprincipat

Els dos coprínceps —el bisbe d'Urgell i el president francès—, els veguers, i com funciona un cap d'estat compartit. No hi ha cap altre cas al món.

**Veu per defecte d'aquesta branca:** `compilada`.

> Branca buida. El contingut arriba a la fase 2 (`temes/`) i a la fase 3 (`parla/`),
> amb investigació profunda i la font citada a cada afirmació.
