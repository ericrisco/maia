# El Consell paga el nunci i l’advocat, 1820

## Dos oficis que fan funcionar el govern

Tres rebuts del fons de l’Arxiu de les Set Claus documenten salaris pagats durant
1820:

- el **16 de maig**, el Consell paga el rebut del nunci **Pau Serra**
  (**ASC-00638**);
- el **18 de desembre**, torna a aparèixer un rebut de Pau Serra, identificat
  explícitament com a **nunci i oficial de justícia** (**ASC-00640**);
- el **21 de desembre**, es paga el salari de l’advocat **Ignasi Solans
  d’Areny** (**ASC-00641**), per mitjà d’Antoni Mitjavila Jordà, de Sornàs.

La sèrie mostra que la justícia quotidiana requeria oficis remunerats: un agent
que executava o comunicava les decisions i un advocat que aportava assessorament
jurídic.

## Què aporta a la història institucional

Els rebuts no són actes solemnes ni lleis. Són comptabilitat de funcionament.
Precisament per això permeten veure el Consell com una administració que pagava
persones concretes per mantenir la justícia en marxa.

El segon rebut del nunci dins el mateix any no prova per si sol un salari anual,
una renovació o un canvi de funcions. Només confirma dos pagaments catalogats i
la identificació del càrrec. Igualment, el rebut de l’advocat no explica quin
plet o consulta va motivar el pagament.

## Buits registrats

- Falten els imports i la transcripció completa dels tres rebuts.
- No sabem quines funcions exactes exercia Pau Serra ni si el segon pagament era
  una quota ordinària o extraordinària.
- No consta el plet, informe o consulta associat a Ignasi Solans d’Areny.
- Cal buscar altres rebuts del mateix any per saber si formaven part d’una sèrie
  salarial regular.
