# L'Armari de les Set Claus

## L'objecte

A la sala del Consell de la
**[Casa de la Vall](./casa-de-la-vall.md)** hi ha **un armari amb set panys**.

**Cada parròquia en té una clau.** Les set claus són **dels cònsols de les set
parròquies**.

**L'armari no es pot obrir si no hi són les set parròquies.**

([Viquipèdia](../../../fonts/viquipedia-ca.md))

## Per què això és extraordinari

**És la constitució del país convertida en moble.**

Andorra és un estat fet de
[set parròquies](../comuns-i-parroquies/les-set-parroquies.md) que no es manen
les unes a les altres. Aquella estructura no està només escrita en normes: està
**materialitzada en un pany**. Ningú no pot accedir sol als documents que
acrediten els drets del país. **La unanimitat és un objecte de fusta.**

I hi ha un detall millor encara.

## Fins al 1978 eren SIS claus

També se'l coneix com a **Armari de les Sis Claus**, perquè **històricament
només tenia sis panys**, corresponents a **les sis parròquies històriques**
d'Andorra.

**El setè pany s'hi va afegir el 1978**, amb la **incorporació
d'Escaldes-Engordany com a setena parròquia**.

**Van canviar l'armari perquè havia canviat el país.** Quan Andorra va passar de
sis a set parròquies, algú va haver d'anar-hi i **obrir-hi un forat nou**.

Això lliga amb el que el corpus té sobre
[les set parròquies](../comuns-i-parroquies/les-set-parroquies.md) i sobre
[Escaldes-Engordany](../../territori/parroquies/escaldes-engordany/escaldes-engordany.md),
que és **la parròquia jove d'Andorra** — i ara se sap que la seva creació té una
empremta física al parlament.

## Què hi ha a dins

| | |
| --- | --- |
| **Documents conservats** | **5.859** |
| **Franja de dates** | **1176 – 1978** |

**Vuit segles de documentació d'un país, en un armari.**

Contingut documentat:

- Una petició del **segle XIV** de **Miquel Moles** i **Pere Bonit**, **síndics
  de les valls d'Andorra**, a les **Corts Generals de la Corona d'Aragó**, per
  **importar mercaderies del Principat de Catalunya**;
- **rendes episcopals**;
- **actes notarials**;
- **escrits del Consell**.

**El document més antic és del 1176** — **un segle abans del
[Pareatge](../../historia/pareatge/el-pareatge.md)**. Andorra té documentació
pròpia anterior al document que en fixa el règim polític.

I la primera petició coneguda dels síndics andorrans és **per poder comerciar**.
Encaixa amb tot el que el corpus té sobre
[el comerç](../../economia/comerc/comerc.md) i
[el contraban](../../historia/contraban/contraban.md): **la relació d'Andorra amb
la frontera com a activitat econòmica té vuit segles**, no seixanta anys.

## L'armari i el fons ja no són al mateix lloc

L'**Arxiu de les Set Claus va ser transferit el 1993 a l'Arxiu Nacional**.

L'armari **es va conservar secularment a la Casa de la Vall**, des d'una **data
incerta, probablement des de principis del segle XV, amb la creació del
Consell**.

Val la pena ser precís amb la distinció, perquè és fàcil de confondre:
**l'«Arxiu de les Set Claus» és el fons documental; l'«Armari de les Set Claus»
és el moble.** El fons és a l'Arxiu Nacional des del 1993; el moble és a la Casa
de la Vall.

## En línia

La premsa andorrana recull que **«Les Set Claus»** han passat **en línia**, i
consta un **inventari de l'Arxiu de les Set Claus publicat pel Govern** en PDF.

**Buit registrat, i és el més accionable del corpus:** aquell inventari dona **la
llista dels 5.859 documents**. Per al camp `epoca` del projecte, **és el
jaciment d'andorrà escrit històric més ben delimitat que s'ha localitzat fins
ara** — amb datació document a document, del 1176 al 1978.

## El que falta

- **L'inventari**, buidat.
- Com és l'armari **físicament**: fusta, mides, època, qui el va fer.
- Si les set claus **encara existeixen** i qui les guarda avui.
- **Quan es va obrir per última vegada** amb les set claus posades.
- Les **catorze exposicions virtuals** de l'Arxiu Nacional, accessibles al seu
  web i **no consultades**.
- Quines eren **les sis parròquies històriques** i quan exactament es constitueix
  Escaldes-Engordany.
