# Una concòrdia regula el pas dels ramats a Santa Cecília, 1543

El **14 de gener de 1543**, el Capítol de **Santa Maria de Castellbò** va fer
una concòrdia amb **Gervasi Moles** i **Bernat Rossell**, representants de les
Valls d’Andorra. La fitxa de l’**ASC-3670** situa l’acord a les terres de Santa
Cecília, a Castellbò, i n’identifica l’objecte: el **passatge** i el
**pasturatge**.

La peça documenta una solució negociada entre les Valls i un capítol eclesiàstic.
Això amplia la seqüència iniciada amb les ordinacions de 1340: els conflictes pel
moviment dels ramats no només generaven queixes contra oficials, sinó també
acords específics amb institucions que controlaven terres i passos.

La comparació és útil però limitada. El catàleg no diu quines taxes, dates,
obligacions o sancions contenia la concòrdia, ni si substituïa les ordinacions
anteriors. Per tant, només podem afirmar el marc de l’acord i les parts que hi
intervenen.

## Buits registrats

- No hi ha una transcripció diplomàtica ni una traducció del foli.
- No coneixem les clàusules concretes sobre pas, pasturatge, taxes o sancions.
