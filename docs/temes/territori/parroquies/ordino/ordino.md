# Ordino

| | |
| --- | --- |
| Ordre protocol·lari | **3** de 7 |
| Superfície | 89 km² |
| Població (2023) | 5.440 |
| Subdivisions | **quarts** |

Tercera en l'ordre protocol·lari. La Valira del Nord la travessa.

## Al seu terme

- **Sant Martí de la Cortinada**, joia del romànic andorrà, arquitectura original dels segles XI i XII.
- **[Sornàs](../../../cultura/llegendes/la-bruixa-de-sornas.md)**, amb la figura de dona a la roca.
- El **Roser d'Ordino**, del 3 al 6 de juliol.
- Dividida en **quarts**.

## Ordino a l'Atles lingüístic

Ordino és **una de les dues localitats andorranes enquestades per l'ALDC**, el 1972.
Els informants van ser **Ventura Gaspar i Torres** i **Josep Ariost i Solana**, de
setanta-set i setanta-vuit anys, tots dos pagesos.

Bona part del que se sap amb precisió de la [fonètica](../../../llengua/fonetica/fonetica.md)
andorrana surt d'aquestes enquestes — i, per tant, d'aquesta parròquia. Ordino diu
*avellaners*, *unflada*, *penellons*, *serrell*, *brasó*, *picaó*; Santa Coloma
diu altres coses. Són a menys de vint quilòmetres.
