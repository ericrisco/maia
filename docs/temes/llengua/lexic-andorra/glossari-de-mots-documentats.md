# Glossari de mots andorrans documentats

Aquest és **material lèxic en brut**, tal com el recull Joan Sans Urgell a la
ponència de l'IEC ([font](../../../fonts/iec-vocabulari-andorra.md)), a partir
del *Vocabulari d'Andorra* (Badia, Ganyet i Pérez, 1992), el *Diccionari
enciclopèdic d'Andorra* (2007), i els treballs d'Anglada (1974), Riera (1992,
1996) i Pantebre (1997).

**Avís de lectura.** Cap d'aquests mots no és *veu originària*: són mots
**citats dins d'una font acadèmica**, no parla andorrana recollida per aquest
corpus. Serveixen per **saber què buscar** a la fase 3, no com a mostra de
llengua. I **la majoria no són exclusius d'Andorra**: molts es comparteixen amb
el Pallars, l'Alt Urgell i la Ribagorça. Un mot d'aquesta llista és
*probablement andorrà*, no *només andorrà*.

## Vocabulari jurídic i administratiu

| Mot | Significat |
| --- | --- |
| **parròquia** | unitat administrativa de nivell local |
| **comú** | corporació local (≈ ajuntament), i l'edifici on és |
| **casa comuna** | equivalent de la casa de la vila |
| **quart**, **veïnat** | figures administratives ≈ pedania |
| **cònsol** | màxima autoritat local (≈ alcalde, batlle, paer en cap) |
| **batlle** | **jutge de primera instància** — femení invariable, *la batlle*, no *batllessa* |
| **batllia** | jutjat de primera instància |
| **raonador -a del ciutadà** | ombudsman |
| **síndic** | president del parlament — **no** l'ombudsman, que és el sentit a Catalunya |
| **nunci núncia** | conserge de l'administració pública (no només pregoner) |
| **manador -a** | pregoner |
| **bander** | guarda forestal (≈ agent rural) |
| **arrest** | acord comunal — del francès *arrêt*. Documentat al segle XVII: *Areste lo dit Consell...* |
| **cot** | multa imposada per un consell per incompliment d'un deure |
| **ordinació** | norma d'un comú |
| **foc i lloc** | impost parroquial |
| **consòrcia** | unió de persones amb un interès comú que s'ajuden en cas de necessitat |
| **providència** | resolució d'un jutge sobre un tràmit processal |
| **aute** | interlocutòria (adaptació del castellà *auto*) — el DIEC2 el recull **marcat com a andorrà** |
| **quèstia** | pagament d'origen feudal als dos cosenyors, **fins al 1993** |
| **veguer** | representant de cada copríncep — **obsolet des del 1993** |
| **visura** / **veedoria** | un tipus de tribunal |
| **cosenyoriu** | el règim de dos caps d'estat (**no** *consenyoriu*) |
| **llevador -a** | qui porta els comptes — **vigent als quarts andorrans** |
| **emprivari** | titular de l'ús d'un empriu |
| **defens** | privar que el bestiar pasturi en un predi, o que ho faci sense pagar |
| **eixivern** | eixivernada |
| **peixena** | zona aglevada on viu el bestiar a l'estiu |
| **peixeder** | lloc on els animals peixen |
| **padral** | registre d'animals de renda |
| **rebaixant** | terreny comunal boscós per sota les pastures d'alta muntanya |
| **fresa** | lloc on els peixos fresen (habitual en legislació de pesca) |

## Innovacions locals

| Mot | Significat |
| --- | --- |
| **clípol** | autobús — **encreuament de *Climent* i *Pol***, nom i cognom dels empresaris que van crear l'empresa de cotxes de línia. En recessió davant *bus*. També se n'ha dit **platillo** |
| **ludoescola** | ludoteca |
| **primera / segona ensenyança** | primària / secundària |
| **bàtxel·lor** | grau universitari (de l'anglès *bachelor*) |
| **parapública** | empresa pública (del francès *parapublique*) |
| **fronterer -a** | qui treballa a Andorra i resideix a les zones veïnes |
| **transfronterer -a** | a banda i banda d'una frontera |
| **pleta** | **urbanització** (sentit nou; tradicionalment, lloc on es guarda bestiar) |
| **borda** | restaurant típic; també antiga borda rehabilitada per a caps de setmana |
| **andorranitzar / -ització** | fer presents els elements culturals andorrans en la societat nouvinguda i les escoles |
| **andorranitat** | qualitat d'andorrà |
| **andorranisme** | paraula o expressió típica d'Andorra; devoció a les coses d'Andorra |
| **termoludisme** | turisme termal (el TERMCAT va preferir *turisme termal*; Andorra continua dient *termoludisme*) |
| **fer cunya** | disposar els esquís en V — castellanisme arrelat; abans es recomanava *fer tascó* |

## Gal·licismes propis

**reglatge** (ajust dels esquís) · **enquesta** (investigació) · **convivial**
(amigable, en informàtica) · **balotatge** (segona volta electoral; ja no s'usa,
la legislació no ho preveu) · **rentrée** (inici de curs, **pronunciat amb erra
francesa**) · **lycée** (no *liceu*) · **populació**, **redutable**,
**partenari**, **bricolar**, **robinet** (Anglada, anys setanta) ·
**mutarda** 'mostassa', **buquet** 'ram de flors', **regissor** 'encarregat
d'una explotació agrària' — aquests tres **en boca d'andorranes nascudes a
principi del segle XX**, recollits a *Dones d'Andorra* (2006)

**Nota geogràfica:** a les **parròquies altes, especialment Canillo**, més
propera a França, hi ha hagut **tradicionalment més gal·licismes** que a la
resta del país. El lèxic andorrà no és uniforme dins d'Andorra.

## L'expressió

> **fer-se l'andorrà** — 'fer-se el desentès'

## El que falta

**Cada mot d'aquesta llista mereix comprovació independent**: si és viu avui, en
quina parròquia, en quina generació, i amb quina pronúncia. Aquesta fitxa és
**un índex de feina**, no una descripció de la parla real.

Les fonts primàries segueixen sense obrir: el ***Vocabulari d'Andorra*** (1992),
el ***DEA*** (2007), *El parlar d'Andorra* de **Pantebre** (1997) i l'estudi
dialectològic de **Riera** (1992).
