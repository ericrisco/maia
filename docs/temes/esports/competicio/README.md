## Les quatre escales de l'esport andorrà

El corpus les separa perquè **el resultat canvia radicalment segons contra qui
es competeix**:

| Escala | Com hi va Andorra |
| --- | --- |
| **[Jocs dels Petits Estats](./els-jocs-dels-petits-estats.md)** | **Hi guanya molt.** Rècord de **38 medalles** el 2025 |
| **[Jocs del Mediterrani](./els-altres-jocs.md)** | **Una medalla en set edicions**, i és del 2026 |
| **[Jocs Europeus](./els-altres-jocs.md)** | **Cap medalla en tres edicions** |
| **[Jocs Olímpics](./andorra-als-jocs-olimpics.md)** | **Cap medalla en cinquanta anys.** Millor resultat: **6a** |

**Aquesta escala és, probablement, la cosa més útil que aquesta branca pot
ensenyar sobre l'esport d'un microestat**, i el corpus la marca com a
**observació pròpia**: cap font la presenta així.
