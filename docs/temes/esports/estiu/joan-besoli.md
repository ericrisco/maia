# Joan Besolí i Lluelles

## El fet

**Joan Besolí Lluelles, nascut el 17 de setembre del 1959**, és un **tirador de
fossa olímpica andorrà que va competir als Jocs de Barcelona, el 1992**
([font](../../../fonts/wikipedia-atletes-andorrans.md)).

**Tenia 32 anys.**

## Completa la sèrie del tir andorrà

**[La fitxa d'Esther Barrugués](./esther-barrugues.md) deia que el corpus tenia
set edicions de tir olímpic andorrà.** **Amb aquesta fitxa i la de [Gerard
Barcia](./gerard-barcia.md), la sèrie s'allarga:**

| Jocs | Qui |
| --- | --- |
| 1976 | [Esteve Dolsa](./esteve-dolsa.md), [Joan Tomàs Roca](./joan-tomas-roca.md) |
| 1980, 1984 | [Francesc Gaset](./francesc-gaset.md), Tomàs Roca |
| **1992** | **Joan Besolí** |
| **1996** | **[Gerard Barcia](./gerard-barcia.md)** |
| 2000 | Tomàs Roca |
| 2004 | Francesc Repiso Romero |
| 2012 | Tomàs Roca |
| 2016 | [Esther Barrugués](./esther-barrugues.md) |

**Nou edicions i vuit tiradors.** **El tir és, de tots els esports d'estiu, el
que Andorra ha mantingut més temps als Jocs: del 1976 al 2016, quaranta anys.**

## El cognom

**Besolí és el mateix cognom que [Toni Besolí](./toni-besoli.md)**, judoka
olímpic a Atenes 2004, nascut el 1976.

**El corpus no afirma cap parentiu** i **registra la coincidència**: **dos
Besolí olímpics andorrans, de disciplines diferents, amb disset anys de
diferència.**
