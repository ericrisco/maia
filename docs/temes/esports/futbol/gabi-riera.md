# Gabriel «Gabi» Riera i Lancha

## El fet

**Gabriel Riera Lancha**. **Davanter**
([font](../../../fonts/wikipedia-atletes-andorrans.md)).

| | |
| --- | --- |
| **Naixement** | **Andorra, 5 de juny del 1985** |
| **Internacional** | **2004-2017** |
| **Partits** | **40** |
| **Gols** | **1** |

**UE Engordany**, a la **Primera Divisió andorrana**.

## Un dels que es queden

**El corpus reté aquesta fitxa** perquè **Riera és dels pocs internacionals
andorrans que juguen la carrera dins del país**, com **[Cristian
Martínez](./cristian-martinez.md)**.

**La majoria passen pel sistema espanyol** — vegeu [Marc García](./marc-garcia.md)
i [la selecció](./la-seleccio.md).

**Tretze anys de selecció i un gol.**
