# Samir Bousenine

## El fet

**Samir Bousenine**, nascut  el 7 de febrer del 1991.
**Extrem dret** ([font](../../../fonts/wikipedia-atletes-andorrans.md)).

| | |
| --- | --- |
| **Naixement** | **—, 7 de febrer del 1991** |
| **Partits amb Andorra** | **4** |
| **Posició** | Extrem dret |

**FC Andorra**, **FC Santa Coloma**, **TF Croix-Daurade**, **AS Tournefeuille**, **US Revel**, **FC Lusitanos**, **UE Engordany** i **Inter Club d'Escaldes**.

## El que en destaca

**Tres dels seus vuit clubs són de la regió de Tolosa** —Croix-Daurade, Tournefeuille i Revel. **És l'únic futbolista de la branca amb una carrera repartida entre Andorra i el futbol regional francès**, i **el corpus ho registra** perquè **gairebé tots els altres van cap al sud, a Catalunya i l'Aragó.**
