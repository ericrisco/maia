# Laia Solé

## El fet

**Laia Solé**, nascuda el **7 de gener del 2005**.
**Migcampista i defensa**
([font](../../../../fonts/wikipedia-futbol-femeni-andorra.md)).

| | |
| --- | --- |
| **Naixement** | 7 de gener del 2005 |
| **Partits amb Andorra** | **6** |

## El que en destaca

**La font la situa a dues posicions diferents i amb dos dorsals**, 14 i 20, a la mateixa convocatòria. **Contradicció registrada, no arbitrada.** **La darrera convocatòria documentada és contra Gibraltar, el 26 d'octubre del 2024.**

## El que falta

- **Quina és la seva posició**, i els seus sis partits.
