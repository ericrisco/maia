# Carlos Eduardo «Edu» Peppe i Britos

## El fet

**Carlos Eduardo «Edu» Peppe i Britos**, nascut a Montevideo (Uruguai) el 28 de gener del 1983.
**Migcampista** ([font](../../../fonts/wikipedia-atletes-andorrans.md)).

| | |
| --- | --- |
| **Naixement** | **Montevideo (Uruguai), 28 de gener del 1983** |
| **Partits amb Andorra** | **21** |
| **Posició** | Migcampista |

**Defensor Sporting** (2002), **Cerrito** (2005) i **UE Sant Julià** des del 2007.

## El que en destaca

**És el segon uruguaià que el corpus troba a la selecció andorrana**, amb **[Sebastián Gómez](./sebastian-gomez.md)**. **I el seu recorregut és el més llarg des de més lluny**: **Defensor Sporting és un club de la primera divisió uruguaiana**, i va acabar jugant a la Primera Divisió d'Andorra.
