# Adrián «Adri» Rodrígues i Gonçalves

## El fet

**Adrián «Adri» Rodrígues i Gonçalves**, nascut a Andorra la Vella el 14 d'agost del 1988.
**Lateral dret** ([font](../../../fonts/wikipedia-atletes-andorrans.md)).

| | |
| --- | --- |
| **Naixement** | **Andorra la Vella, 14 d'agost del 1988** |
| **Posició** | Lateral dret |

Va jugar al **Burgos** espanyol.

## El que en destaca

**Va passar per la sub-21 andorrana abans de debutar amb l'absoluta el 2012**, cosa que el corpus no pot dir de gairebé ningú més d'aquesta branca: **és dels pocs de qui consta el recorregut de base**.
