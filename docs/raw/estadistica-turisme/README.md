## Les xifres clau del 2025

**218 allotjaments** de modalitat hotelera i apartaments turístics —**163
hotels**— amb **29.661 llits**, **menys que els 31.211 del 2021** i que els
**~34.000 del 2014**. **107 empreses d'habitatges d'ús turístic** amb **2.358
habitatges** i **11.403 llits**. **Total del país: més de 42.201 places.**

**28 refugis de muntanya**, 21 dels quals **no guardats**.

**Visitants**: **685.096** el novembre del 2025 i **768.866** el desembre
(+12,2%).
