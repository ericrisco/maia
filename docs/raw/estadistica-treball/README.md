## Què conté cada nota

Nombre d'assalariats, massa salarial, **salari mitjà i medià**, tot això
**per sector i per ocupació**, amb dades ajustades estacionalment i un
**histograma de la distribució dels salaris declarats** amb l'**interval modal**.

## Les xifres del maig del 2026

**44.729 assalariats** (+2,5%) · **massa salarial 123,47 M€** (+10,4%) ·
**salari mitjà 2.760,46 €** (+7,7%) · **salari medià 2.235,73 €**, el **81,0%**
del mitjà · **interval modal 1.500-1.600 €** amb el **5,4%** dels assalariats.

Extrems per sector: **sistema financer 4.972,10 €**, **llars que ocupen personal
domèstic 1.936,45 €**, **hoteleria 2.151,69 €** amb 4.678 assalariats.
