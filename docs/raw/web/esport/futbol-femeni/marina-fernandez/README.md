La fitxa web de trajectòria situa la seqüència **Pardinyes CF (2014–2016)**,
**ENFAF (2017)**, **SE AEM (2017–2019)** i **ENFAF (des de 2019)**. La mateixa
fitxa fa solapar ENFAF i AEM el 2017; no permet decidir si és una temporada
partida o una doble inscripció.

La peça de RTVA del **24 d'agost de 2022** documenta un altre pas posterior:
Fernández va deixar temporalment l'ENFAF per jugar al segon equip de l'AEM de
Lleida, entrenant entre setmana a Andorra i anant a Lleida els divendres.

Fitxers conservats: [trajectòria](./wikipedia-marina-fernandez.html) i
[peça RTVA](./rtva-marina-aem-2022.html). La pàgina de trajectòria és una font
secundària; drets de reproducció pendents i fora de qualsevol dataset.
