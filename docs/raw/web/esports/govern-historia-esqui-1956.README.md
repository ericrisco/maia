# De les aigües termals al Duralex — història de l’esquí d’Andorra

Aquesta carpeta conserva el PDF i l’extracció textual del catàleg històric
il·lustrat del Govern d’Andorra. El pròleg relaciona el creixement comercial i
turístic dels anys cinquanta amb la creació del Sindicat d’Iniciativa, el projecte
d’un telesquí d’Arinsal sol·licitat el 1956 i la inauguració del primer telesquí
llarg durant la temporada 1957–1958.

La font és una síntesi institucional. No conserva l’expedient tècnic, els plànols
ni la resolució administrativa del projecte d’Arinsal.
