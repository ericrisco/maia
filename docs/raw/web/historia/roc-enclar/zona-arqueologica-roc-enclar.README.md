# Zona arqueològica del Roc d’Enclar

Fitxa d’inventari del Govern d’Andorra per al jaciment del Roc d’Enclar, declarat
zona arqueològica d’interès cultural. La pàgina resumeix cinc períodes i remet a
la monografia **Roc d’Enclar: Transformacions d’un espai dominant (segles
IV–XIX)**, publicada pel Govern el 1997.

## Fitxers locals

- `zona-arqueologica-roc-enclar.html` — còpia de la pàgina institucional.
- `zona-arqueologica-roc-enclar.txt` — extracció de text per a cerca local.

La síntesi local conserva la periodització de la fitxa, però no substitueix la
monografia d’excavació ni les memòries tècniques del jaciment.
