# La sal i els camins de les mercaderies a Sant Julià de Lòria

Article del Comú de Sant Julià de Lòria descarregat el **23 de setembre de
2026**. La pàgina resumeix, a partir del *Diplomatari de la Vall d’Andorra. Segle
XVII* de Domènec Bascompte, tres episodis de renovació dels privilegis
comercials: 1603, 1606 i 1655.

- `comu-sant-julia-sal-camins-mercaderies.html` — còpia HTML de la pàgina.
- `comu-sant-julia-sal-camins-mercaderies.txt` — extracció local del text.

Per a la fitxa del corpus s’utilitza sobretot el passatge del **14 de juliol de
1606**: la Reial Audiència de Barcelona confirma que els habitants de les Valls
podien treure lliurement queviures de Catalunya, Rosselló i Cerdanya per al
propi consum, i ordena retornar a Miquel Sabater, pagès d’Encamp, dues càrregues
de farina confiscades a la Seu d’Urgell. La pàgina és una font institucional
secundària; la peça d’arxiu i la sentència íntegra continuen pendents.
