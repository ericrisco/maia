# *El coronel Baulard* — La peça del mes (març de 2026)

Pàgina institucional de l’Arxiu Nacional sobre la intervenció de la Gendarmeria
francesa el 1933. Relaciona el clima de vagues de FHASA i l’activitat del
Partit dels Joves d’Andorra amb la crisi política; explica els escrúpols legals
del comandant René Jules Baulard i descriu la seva actuació com a interlocutor
entre els gendarmes i les autoritats andorranes.

La pàgina també resumeix el conflicte de la concessió de FHASA, la reclamació de
12.000 pessetes del Consell, l’arribada de reforços i la retirada de les tropes
després de les eleccions. Conservem l’HTML i l’extracció textual; no hi consta
una llicència específica de reutilització.
