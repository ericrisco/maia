# L’altra guerra mundial i nosaltres — el cas dels soldats turcs


Captura HTML de l’article d’A. Luengo publicat a *Bondia* el 12 d’octubre de
2022. Resumeix la recerca de Joan-Lluís Ayala sobre la Primera Guerra Mundial a
Andorra i descriu l’arribada de sis soldats turcs el 1917, el conflicte entre els
veguers i les mesures de control de viatgers, passaports i queviures.
