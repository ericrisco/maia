# Camp del Perot: memòria arqueològica de Cal Terrissaire

Memòria científica de la intervenció d’urgència feta entre el **23 i el 25 de
maig de 2018** sobre les restes del forn de ceràmica de Cal Terrissaire, al
Camp del Perot de Sant Julià de Lòria. La redacció és d’Òscar Augé Martínez i
porta data de 29 de juliol de 2022.

## Passatges consultats

Les pàgines impreses **11–12** resumeixen el context de Camp Vermell i la
necròpolis excavada el 1991 al Camp del Perot: 47 tombes documentades, 39
excavades, 42 inhumacions i una datació d’ús entre el segle VIII i mitjan segle
XII. Les pàgines **3–9 i 15–24** descriuen el forn de Cal Terrissaire, la seva
estructura, els materials i el context de l’últim terrisser d’Andorra.

La memòria és font directa per a la intervenció de 2018, però el resum de la
necròpolis de 1991 és una referència institucional posterior a aquella
excavació; el corpus ho indica expressament.
