# Andorra, Terra de Bruixes

Còpies consultades el **23 de setembre de 2026**:

- `presentacio.html` i `presentacio.txt` — presentació del projecte i abast de
  la recerca (1400-1700).
- `atles-7.html` i `atles-7.txt` — resum del zenit de la cacera andorrana,
  1621-1629.
- `cercador.html` — pàgina del cercador sense filtres.
- `cercador-1621-pagina-1.html` a `cercador-1621-pagina-4.html` — resultats
  del filtre `tdb_any=1621`.
- `cercador-1621.tsv` — extracció tabular dels 37 resultats: 36 fitxes
  d’acusades i una fitxa de la Concòrdia (1621).

La font és una síntesi institucional amb referències arxivístiques. El corpus
la cita per al context i contrasta els actes concrets amb el Llibre I d’actes
del Consell de la Terra.
