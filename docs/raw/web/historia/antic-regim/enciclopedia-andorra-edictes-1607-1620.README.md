# Andorra a la Gran Enciclopèdia Catalana — edictes de 1607 i 1620

Captura de la veu de la **Gran Enciclopèdia Catalana**. La síntesi identifica els edictes d’Enric IV (1607) i Lluís XIII (1620) com els actes pels quals els drets de la casa de Foix foren incorporats a la corona de França; no substitueix la consulta dels textos originals.
