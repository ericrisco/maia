# La peça del mes — Armari de les Set Claus (2018)

Captura de la pàgina oficial del Govern d’Andorra. La fitxa de juny de 2018 documenta el moble, l’afegit de la setena clau el 1978 i la transferència del fons a l’Arxiu Nacional el 22 de març de 1993; no dona la data de l’última obertura física amb les claus.
