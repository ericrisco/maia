# Lles i Andorra signen una concòrdia pels emprius, 1570

La fitxa **ACA-5367** d’**Arxius en Línia** data el document el **22 de juny de
1570**. El descriu com una còpia de la concòrdia i avinença signada a **Lles**
entre **Antoni Sirvent**, cònsol i síndic de la baronia de Lles, i **Andrea
Salvany**, mercader de Perpinyà i procurador de **Guiomar d’Ortafà**, senyora de
Lles i Travesseres, d’una banda, i els cònsols de la parròquia d’Andorra, de
l’altra.

La fitxa situa l’acord dins un litigi a la **Reial Audiència de Barcelona** per
uns **penyoraments** fets pels de Lles als andorrans, que sostenien tenir empriu
a les muntanyes de Lles. La rendició original és un pergamí d’un foli,
digitalitzat en dues pàgines; s’han revisat visualment el recto i el verso. El
PDF no té capa de text útil i no se’n fa una transcripció diplomàtica.
