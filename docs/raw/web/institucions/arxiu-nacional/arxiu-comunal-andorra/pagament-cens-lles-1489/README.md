# Un pagament de cens que el batlle de Travesseres no vol rebre, 1489

La fitxa **ACA-5362** d’**Arxius en Línia** data la unitat el **28 de març de
1489**. La descriu com l’acta del pagament del cens anual que la **parròquia
d’Andorra la Vella** està obligada a pagar per raó de l’empriu a les muntanyes de
**Lles i Travesseres**, i de la petició de l’**àpoca** corresponent. El catàleg
afegeix que **Joan Mor**, batlle de Travesseres, es nega a acceptar el cens
seguint les instruccions del seu senyor, **Pere d’Ortafà**.

La rendició original és un foli digitalitzat en dues pàgines; s’han revisat
visualment el recto i el verso. El PDF no té capa de text útil i no se’n fa una
transcripció diplomàtica ni es quantifica el cens.
