# La rodalia de l’empriu de la Pera es descriu per fites, 1792

La fitxa **ACA-335** d’**Arxius en Línia** data la unitat l’any **1792** i la
descriu com la **rodalia de l’empriu** que té la parròquia d’Andorra amb els de
**Lles i Aransa**, al terme o muntanya de la **Pera**.

La rendició original descarregada consta de tres pàgines d’imatge manuscrites.
S’han revisat visualment les tres. El text segueix una descripció contínua de
fites i accidents del terreny; no és un mapa i el PDF no té capa de text útil.
No se’n fa una transcripció diplomàtica ni una reconstrucció cartogràfica.
