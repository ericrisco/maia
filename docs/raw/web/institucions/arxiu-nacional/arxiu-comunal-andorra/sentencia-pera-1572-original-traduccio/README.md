# L’original i la traducció d’una sentència sobre l’empriu de la Pera, 1572

Les fitxes **ACA-323** i **ACA-324** comparteixen la data **18 de desembre de
1572**, la descripció d’«original i traducció de la sentència» sobre l’empriu
d’Andorra a la muntanya de la Pera i el número d’inventari **23680**. Les dues
consten com una unitat documental composta de 14 folis.

Les rendicions digitals són diferents: **ACA-323** té set pàgines i s’obre amb
una capçalera que identifica una traducció castellana del document original;
**ACA-324** té sis pàgines i conserva el text original en llatí, amb anotacions i
testimonis posteriors visibles. S’han revisat visualment totes les pàgines de
les dues rendicions. Cap PDF no té capa de text útil i no se’n fa una
transcripció diplomàtica.
