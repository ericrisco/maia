# Un rebut del cens anual que Andorra paga a Lles, 1600

La fitxa **ACA-2339** d’**Arxius en Línia** data la unitat el **24 d’agost de
1600** i la descriu com els rebuts del **cens anual** que la **parròquia
d’Andorra** paga a la **Baronia de Lles** pel seu empriu a la muntanya de Lles.

La fitxa declara una unitat documental composta de **31 folis**, però el fitxer
original que el portal deixa descarregar té una sola pàgina i consta com a no
previsualitzable en les metadades. S’ha revisat visualment aquesta pàgina: és un
rebut manuscrit amb la data de 1600. No es presenta com una rendició completa de
la unitat ni se’n fa una transcripció diplomàtica.
