# Les declaracions de 1631 ja tenen còpia digital directa

El portal **Arxius en Línia** ofereix les tres unitats que l’inventari de l’Arxiu
Comunal descriu com **ACA 46–48**. Les fitxes daten les peces el **1631** i les
descriuen com a declaracions de veïns de la Cerdanya sobre el dret dels
andorrans de treure **blat i altres mercaderies** de la Cerdanya i portar-los cap
a Andorra. Això permet passar de la descripció de l’inventari a les imatges de
les fonts primàries.

## Unitats digitalitzades

- **ACA-46** ([fitxa oficial](https://www.arxiuenlinia.ad/fotoweb/archives/5004-Documents-textuals/Documents/ACA/ACA_0046.pdf.info)):
  fitxa datada el 1631, extensió indicada de 3 folis.
- **ACA-47** ([fitxa oficial](https://www.arxiuenlinia.ad/fotoweb/archives/5004-Documents-textuals/Documents/ACA/ACA_0047.pdf.info)):
  fitxa datada el 1631, extensió indicada de 3 folis.
- **ACA-48** ([fitxa oficial](https://www.arxiuenlinia.ad/fotoweb/archives/5004-Documents-textuals/Documents/ACA/ACA_0048.pdf.info)):
  fitxa datada el 1631, extensió indicada de 3 folis.

Les imatges s’han revisat visualment. S’hi veuen declaracions manuscrites en
forma d’interrogatori, amb testimonis de diversos llocs de la Cerdanya i
referències al pas de blat i mercaderies cap a les Valls. Aquesta observació no
és una transcripció diplomàtica: la lletra i el deteriorament exigeixen una
lectura paleogràfica específica. L’extracció amb `pdftotext` no produeix text
útil.
