# Un procés judicial llarg pels emprius de Cantabrà i la Pera, 1542

La fitxa **ACA-322** d’**Arxius en Línia** data la unitat el **1542** i la
descriu com el procés judicial del litigi entre **Andorra la Vella** i els
diversos senyors de **Lles** per les muntanyes de **Cantabrà** i **la Pera**.
El catàleg classifica la peça dins dels processos i litigis sobre emprius i
límits territorials.

La fitxa indica **28 folis**. La rendició original local té 29 pàgines
d’imatge, amb un registre manuscrit continuat i cobertes o pàgines de guarda.
S’han revisat visualment les primeres pàgines i el desenvolupament del registre;
el PDF no té una capa de text útil i no se’n fa una transcripció diplomàtica.

ACA-322 és una peça de procés, no una sentència resumida. Relaciona la venda de
l’empriu documentada a ACA-282 (1475) amb la sentència de la Reial Audiència
descrita a ACA-5368 (1572), però el catàleg no permet reconstruir el desenllaç
ni afirmar que totes tres unitats siguin un sol expedient.
