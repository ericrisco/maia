# Arxiu Diocesà d’Urgell — fitxa del cercador *Arxius de Catalunya*

Fitxa oficial de la Generalitat de Catalunya per a l’**Arxiu Diocesà d’Urgell**
(ADU), a la Seu d’Urgell. Indica un abast cronològic dels **segles XIV–XX**,
523,7 metres lineals, consulta amb document d’identitat i el correu
`arxiudiocesa@bisbaturgell.org`.

Aquesta fitxa no descriu les unitats documentals de la correspondència de Justí
Guitart ni els expedients de Josep Tarongí. Serveix per deixar constància de la
custòdia, l’abast i la via pública de consulta del fons que les fonts
secundàries citen.

El repositori conserva l’HTML per a verificació. No hi consta una llicència
específica de reutilització.
