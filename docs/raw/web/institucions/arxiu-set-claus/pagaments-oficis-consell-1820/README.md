# El Consell paga el nunci i l’advocat, 1820

Aquest paquet reuneix tres rebuts de salaris del Consell:

- **ASC-00638** (16/05/1820): rebut del nunci **Pau Serra**;
- **ASC-00640** (18/12/1820): un segon rebut del nunci, identificat també com a
  oficial de justícia;
- **ASC-00641** (21/12/1820): rebut del salari de l’advocat **Ignasi Solans
d’Areny**, pagat per Antoni Mitjavila Jordà, de Sornàs.

Les peces estan classificades com a pagaments, rebuts i salaris. La seqüència
permet veure dos moments de pagament del nunci i un pagament d’assessorament
jurídic dins el mateix any.
