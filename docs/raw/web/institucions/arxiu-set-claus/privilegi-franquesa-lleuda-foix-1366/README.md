# Extracte del privilegi de franquesa de lleuda, 1366

La fitxa pública d’**Arxius en Línia** descriu l’ASC-1187 com un extracte d’un
privilegi del comte de Foix **Gastó III, Phebo**, que atorgava als habitants de
les valls d’Andorra la **franquesa de lleuda a les muntanyes de Foix**. El catàleg
data el privilegi en **1366** i indica que la còpia conservada és del **segle
XVII**, sense data pròpia.

La rendició és un foli manuscrit d’una pàgina. La capçalera i el text són una
còpia o extracte posterior, no el privilegi original de 1366. S’ha revisat
visualment tota la pàgina; l’escriptura cursiva i la marca d’aigua del portal no
permeten obtenir una transcripció fiable amb OCR.
