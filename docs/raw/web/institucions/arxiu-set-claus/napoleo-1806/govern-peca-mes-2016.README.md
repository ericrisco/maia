# Còpia del decret de Napoleó I sobre Andorra — peça del mes (març de 2016)

Pàgina institucional que presenta una còpia del decret de Napoleó I conservada
a l’**Arxiu de les Set Claus**, amb referència **ASC 2500**, datada el **27 de
març de 1806**. El Govern resumeix que el decret retorna els privilegis,
accepta el pagament de la quèstia i fa regir les exportacions pel decret de
1767.

La pàgina distingeix aquesta còpia **ASC 2500** del registre **ASC-3709** del
portal Arxiu en Línia. Es conserva com a font institucional de context i no
com si fos la mateixa unitat documental.

No hi consta una llicència específica de reutilització; es conserva per a
lectura i citació.
