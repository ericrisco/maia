# ASC-3709 — Decret de Napoleó I, 27 de març de 1806

Fitxa del registre de l’**Arxiu de les Set Claus** que descriu el document com
el decret pel qual Napoleó I publica el restabliment de les relacions de
coprincipat amb Andorra a instància dels habitants de les Valls.

El registre dona la signatura **ASC-3709**, data **27/03/1806**, un foli, el
fitxer remot `ASC_03709.pdf` i els descriptors Napoleó I, Hugues-Bernard Maret i
la Prefectura de l’Arieja. El corpus conserva la fitxa HTML i la imatge de
previsualització publicada pel portal; la fitxa del portal indica que el PDF
remot té 289 KB.

La imatge permet comprovar el capçal «Empire français», la Prefectura del
Departament de l’Arieja, la data de les Tuileries i el segell de l’Armari de
les Set Claus. La lectura completa dels articles es fa amb la transcripció
MJP, conservada en una font separada; no es presenta aquesta previsualització
com una edició paleogràfica.

La pàgina és un registre institucional d’accés públic; no hi consta una
llicència específica de reutilització. Es conserva per a lectura, citació i
verificació del registre.
