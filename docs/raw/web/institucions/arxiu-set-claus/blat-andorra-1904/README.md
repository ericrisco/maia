# Blat de Cerdanya repartit a Andorra (les Caldes i Andorra) el 1904

La fitxa pública d’**Arxius en Línia** descriu l’ASC-03961 com una relació o memorial del blat portat de **Cerdanya** i repartit entre els veïns de la parròquia de **Andorra (les Caldes i Andorra)**, amb data **14 d’octubre de 1904**.

La revisió visual de les tres pàgines digitalitzades confirma que el document enumera persones i quantitats en unitats locals manuscrites. Aquest README conserva la descripció i les imatges; no normalitza les unitats ni ofereix una transcripció completa.
