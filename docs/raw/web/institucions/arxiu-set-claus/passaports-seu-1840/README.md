# El governador de Lleida respon sobre els passaports andorrans, 1840

La fitxa pública d’**Arxius en Línia** descriu una resposta de **Manel de
Pedrolo**, governador de Lleida, al síndic d’Andorra sobre l’actitud de l’alcalde
de la Seu d’Urgell respecte dels passaports dels andorrans quan travessaven la
població.

La unitat està datada el **24 de març de 1840**, té dos folis i es classifica
com a ordre sobre passaports i fronteres.
