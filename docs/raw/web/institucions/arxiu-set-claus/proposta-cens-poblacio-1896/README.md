# Un cens per repartir les càrregues de la carretera

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05606 com una carta del
delegat permanent francès **Ardison** al síndic general **Antoni Moles**. Datada
el **21 d’agost de 1896**, proposa fer un cens general de la població andorrana
per repartir millor les imposicions necessàries per construir una carretera.

El document mostra que el recompte de població es plantejava com una operació
administrativa vinculada a les obres i a la contribució dels habitants. No
conté el resultat del cens: és una proposta i una justificació de la necessitat
de conèixer el nombre de persones que haurien de contribuir.
