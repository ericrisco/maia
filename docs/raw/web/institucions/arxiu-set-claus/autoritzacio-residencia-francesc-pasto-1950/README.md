# Un paleta de Castelló demana entrar i residir a Andorra

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05660 com una súplica de
**Pere Font Riba**, veí d’Encamp, al síndic general. Datada el **27 de juny de
1950**, demana autorització d’entrada i residència a Andorra per a **Francesc
Pasto Badena**, nascut a Onda (Castelló de la Plana), perquè treballi com a
paleta en unes obres.

La carta és una petició patronal concreta: el veí que necessita mà d’obra
sol·licita que el treballador pugui entrar i residir a casa seva mentre durin
les obres. No conserva aquí la decisió final ni permet saber si Pasto va ser
admès.
