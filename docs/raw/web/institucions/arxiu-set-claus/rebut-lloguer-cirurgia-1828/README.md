# Un rebut de lloguer signat per un cirurgià el 1828

La fitxa pública d’**Arxius en Línia** identifica l’ASC-00685 com un rebut del
cirurgià **Alonso Argullós** pel pagament del lloguer de casa seva i de l’hort.
La unitat està datada el **31 de març de 1828**, consta d’un foli i està
classificada com a rebut, pagament, lloguer i document relacionat amb metges.

La imatge conservada permet identificar l’emissor, la data i el concepte del
pagament davant del Consell General. L’import manuscrit no es reprodueix perquè
la rendició disponible no permet llegir-lo amb prou seguretat.
