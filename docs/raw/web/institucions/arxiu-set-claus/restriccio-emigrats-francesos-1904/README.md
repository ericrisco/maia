# Una ordre restringeix l’entrada d’emigrats francesos

La fitxa pública d’**Arxius en Línia** descriu l’ASC-04538 com una carta
referent a l’ordre de **no admetre a les valls d’Andorra emigrats francesos**,
tant eclesiàstics com seglars. La unitat està datada el **28 de novembre de
1904**, consta d’un foli i es classifica dins la correspondència sobre
immigració.

La rendició manuscrita conserva una comunicació en català sobre aquesta
restricció. La font prova l’existència d’una instrucció o ordre esmentada en la
carta, però no permet identificar amb seguretat qui la va dictar, durant quant
temps va aplicar-se ni quantes persones va afectar.
