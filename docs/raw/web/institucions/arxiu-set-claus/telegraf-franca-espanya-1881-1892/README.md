# Telègraf entre França, Andorra i la Seu, 1882–1897

Aquesta carpeta conserva la captura local de sis fitxes del catàleg **Arxius en
Línia** sobre la instal·lació, les autoritzacions i les franquícies del telègraf.
Les fitxes tenen permisos **View, Preview i Download**, però no hi consta una
llicència específica de reutilització. Les imatges són previsualitzacions públiques;
no s'hi ha afegit una transcripció del document manuscrit.

| Data | Unitat | Descripció del catàleg |
|---|---|---|

| 1882-09-06 | [ASC-05541](https://www.arxiuenlinia.ad/fotoweb/archives/5004-Documents-textuals/Documents/ASC/ASC_05541.pdf.info) | Papinaud espera que el Consell no s'oposi a una nova línia, després de la destrucció de l'anterior per una banda armada. |
| 1892-02-27 | [ASC-05549](https://www.arxiuenlinia.ad/fotoweb/archives/5004-Documents-textuals/Documents/ASC/ASC_05549.pdf.info) | Bonhoure comunica l'aprovació presidencial francesa de la línia França–Andorra. |
| 1892-11-15 | [ASC-05561](https://www.arxiuenlinia.ad/fotoweb/archives/5004-Documents-textuals/Documents/ASC/ASC_05561.pdf.info) | Lino Freixa informa de l'acord del bisbe i del Govern d'Espanya per unir la Seu d'Urgell i Andorra la Vella. |

| 1897-10-06 | [ASC-05573](https://www.arxiuenlinia.ad/fotoweb/archives/5004-Documents-textuals/Documents/ASC/ASC_05573.pdf.info) | El veguer francès demana justificar les noves franquícies relacionades amb el telègraf. |

Els fitxers `*.asset.json` conserven el descriptor, la data, els folis, els
subjectes, l'URL oficial i el hash de cada previsualització. Els `*.info.html`
són la captura de la fitxa pública consultada.
