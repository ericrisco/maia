# Ordinacions de la Cort contra quadrilles i rodamons, 1580

La fitxa pública d’**Arxius en Línia** descriu l’ASC-03572 com unes ordinacions
de la Cort de les valls d’Andorra, signades pel jutge **Bernat Coromines** i el
veguer **Amany de Queralt**, datades aproximadament el **1580**.

El catàleg resumeix diverses obligacions: prohibir les quadrilles armades,
avisar cònsols o batlles quan se’n trobés una, mantenir una arma a cada casa a
disposició del capità, comunicar baralles, evitar que els dos batlles
s’absentessin alhora i limitar l’acollida de rodamons a les pletes i tavernes.
