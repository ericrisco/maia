# Privilegi de mercat quinzenal, 1512

La fitxa pública d’**Arxius en Línia** descriu l’ASC-1286 com el privilegi
atorgat el **20 de març de 1512** per la reina **Caterina de Navarra** per fer
**mercat cada quinze dies a la vila d’Andorra la Vella**.

El portal cataloga la unitat com un foli i ofereix una rendició de **dues
pàgines d’imatge**, el recto escrit i el verso amb anotacions posteriors. S’han
revisat visualment totes dues cares. El recto és un document manuscrit en
escriptura cursiva amb validació al final; el verso conserva notes de consulta.
L’extracció automàtica no conté text útil.
