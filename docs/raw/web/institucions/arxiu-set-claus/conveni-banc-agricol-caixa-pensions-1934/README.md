# Un conveni bancari andorrà es firma a Barcelona (1934)

La fitxa pública d’**Arxius en Línia** identifica l’ASC-05249 com un conveni entre el **Banc Agrícol i Comercial d’Andorra, SA** i la **Caixa de Pensions per a la Vellesa i d’Estalvis**, datat el **12 de desembre de 1934**. El catàleg el situa a **Barcelona** i el descriu com una unitat documental simple de **quatre folis**.

La previsualització conservada mostra la portada: «Conveni atorgat pel Banc Agrícola i Comercial d’Andorra, S.A. i la Caixa de Pensions per a la Vellesa i d’Estalvis d’Andorra», amb data **Barcelona, 12 de desembre del 1934**. Només s’ha conservat aquesta rendició pública; no es presenta com una transcripció del conveni sencer.
