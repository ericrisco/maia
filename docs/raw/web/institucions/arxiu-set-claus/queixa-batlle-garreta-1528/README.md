# Martí Garreta porta al Consell una decisió del batlle, 1528

La fitxa pública d’**Arxius en Línia** descriu l’ASC-3494 com una queixa de
**Martí Garreta, de les Bons**, presentada davant el **Consell General** en
relació amb una decisió presa pel batlle **Guillem Ramon Colat**. El document
està datat el **6 de setembre de 1528** i s’atribueix al notari **Joan Ortedó**.

La peça conserva la traça d’un conflicte que arriba al Consell després d’una
decisió del batlle. La fitxa no resumeix ni el motiu de la decisió ni la
resposta final del Consell, de manera que el document prova el recurs o la
queixa, però no el resultat del plet.
