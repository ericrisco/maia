# Un passaport andorrà de 1941

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05626 com el passaport
andorrà **número 263**, expedit el **21 de febrer de 1941** pel síndic general
**Francesc Cairat Freixes** a favor de **Filomena Albós Cerqueda**, veïna
d’Escaldes.

El quadern conserva la coberta, les dades físiques, la concessió signada pel
síndic i visats de pas. És una font directa sobre la documentació de la
mobilitat d’una dona andorrana durant la postguerra europea; no permet, per si
sola, reconstruir el viatge efectivament realitzat ni el règim general de
passaports.
