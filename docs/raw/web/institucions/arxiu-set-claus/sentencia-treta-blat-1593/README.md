# Felip II resol sobre la treta de blat i aliments, 1593

La fitxa pública d’**Arxius en Línia** descriu l’ASC-3800 com una sentència del
rei **Felip II**, datada el **22 de novembre de 1593**, en la causa entre les
Valls d’Andorra i el vescomtat de Castellbò. El litigi tracta la possessió del
dret de treure de la zona **blat, vi, oli i altres articles de menjar i beure**
per al manteniment de les Valls.

El catàleg identifica entre els actors el capità general de Catalunya,
**Bernardino de Cárdenas**, el síndic **Bernat Ricart**, diversos síndics
andorrans i els notaris Joan Colat i Pere Miquel Guiu.
