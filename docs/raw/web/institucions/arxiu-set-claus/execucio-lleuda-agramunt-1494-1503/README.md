# Execució de la franquícia de lleuda d’Agramunt, 1494–1503

La fitxa pública d’**Arxius en Línia** descriu l’ASC-03785 com l’actuació de
**Perot de Soldevila**, veguer reial d’Urgell, i **Guillem de Camps**, batlle
d’Agramunt, després que **Antoni Moles**, mercader veí d’Andorra i síndic
procurador, presentés una provisió de **Ferran II del 7 d’octubre de 1493**.
La provisió exigia complir la sentència arbitral del 30 de juny que declarava els
andorrans francs de la lleuda d’Agramunt. El document es data entre el **27 de
gener de 1494 i el 25 de febrer de 1503** i registra la notificació a Antoni
Ubach Cerdà, procurador de Pere de Capdevila, que en demanà còpia.

El portal cataloga la unitat com un foli i ofereix una rendició de **dues
pàgines d’imatge**. El recto conserva l’acte manuscrit amb signes de validació;
el verso mostra el revers i anotacions. S’han revisat visualment totes dues
cares. L’extracció automàtica no conté text útil.
