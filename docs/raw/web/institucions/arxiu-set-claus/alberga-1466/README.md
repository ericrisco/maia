# Alberga i servitud episcopal a Andorra, 1466

Les fitxes públiques d’**Arxius en Línia** descriuen dues peces datades el **3
d’agost de 1466**. A l’**ASC-1318**, el bisbe d’Urgell **Jaume de Cardona**,
a petició dels andorrans, els defineix puntualment del dret d’**alberga** i del
pagament d’una servitud que els exigia el clavari episcopal. El catàleg explica
que aquella servitud havia passat a mans episcopals després que **Joan Sulla**,
notari de Salàs que la cobrava, es rebel·lés contra l’autoritat reial.

A l’**ASC-1319**, el mateix bisbe, després d’escoltar les raons de **Pere de
Paüls**, donzell i veguer episcopal de les valls d’Andorra, deroga la forma de
prestació del dret d’alberga que era vigent. Són dues unitats separades: la
primera està catalogada a Andorra la Vella i la segona al cementiri de Sant
Esteve d’Andorra.
