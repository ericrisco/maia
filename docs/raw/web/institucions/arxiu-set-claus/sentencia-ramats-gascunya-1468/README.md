# Sentència arbitral sobre el robatori de moltons, 1468

La fitxa pública d’**Arxius en Línia** descriu l’ASC-04696 com la sentència
arbitral dictada el **18 de juny de 1468** per **Menaud de Lobie**, senyor de
Milglòs, i **Pere Paüls**, veguers de les valls d’Andorra. El litigi enfrontava
les universitats de les valls amb diversos homes de Gascunya pel robatori, a les
valls d’Andorra, d’uns **moltons propietat de Ramon Vernet, veí de Puigcerdà**.

El portal cataloga la unitat com un foli i ofereix una rendició de **dues
pàgines d’imatge**. El recto és un pergamí molt extens i esvaït; el verso
conserva el revers i una anotació posterior. S’han revisat visualment totes dues
cares. L’extracció automàtica no conté text útil.
