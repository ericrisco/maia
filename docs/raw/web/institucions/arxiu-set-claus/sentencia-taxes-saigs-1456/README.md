# Sentència sobre taxes notarials i canvi de saig a batlle, 1456

La fitxa pública d’**Arxius en Línia** descriu l’ASC-4695 com una sentència del
**7 de juny de 1456** dictada per quatre jutges designats respectivament pel
veguer episcopal i pel comte de Foix. El litigi enfrontava els andorrans i
**Guillem Carreu**, notari de les valls, per l’aplicació de les taxes dels
documents.

La mateixa descripció diu que la sentència obliga Guillem Carreu a complir els
aranzels sobre l’expedició de documents en pública forma i ordena als **saigs**
que es denominin **batlles** i exerceixin l’ofici que abans exercien com a
saigs. És una font primària que fixa en una peça datada la fórmula institucional
que el corpus fins ara coneixia sobretot per una anàlisi posterior.
