# Contribució industrial i de comerç, 1849

La fitxa pública d’**Arxius en Línia** descriu una carta de **Josep López** al
síndic general, datada el **8 de juliol de 1849**. La carta tramet una
disposició de la **Direcció General de Contribucions Directes** segons la qual
els habitants de les valls d’Andorra no estaven exempts del pagament de la
contribució industrial i de comerç.

El document conserva la cadena administrativa entre la Seu d’Urgell, la
Direcció General i el síndic. La rendició permet identificar la disposició i el
seu objecte, però no permet calcular cap quota ni demostrar com es va aplicar a
cada activitat andorrana.
