# Un acord local concreta la treta de blat el 1634

La fitxa **ASC-1302** del portal **Arxius en Línia** data el document el **16 de
maig de 1634** i el descriu com l’acord de **Climent Llinyau Descallar, senyor
de Prullans**, amb **Andreu Pal, síndic de les valls d’Andorra**, sobre alguns
punts de l’extracció de blat del lloc i terme de Prullans. La fitxa situa la
unitat a Talltorta i n’indica 2 folis.

La digitalització té tres pàgines d’imatge. La primera mostra la data i el
desenvolupament de l’acord; les pàgines següents contenen les clàusules i les
validacions. S’ha revisat visualment el conjunt. No se’n fa una transcripció
paleogràfica: l’extracció amb `pdftotext` no produeix text útil.

Aquest document no és ACA 46–48 ni ACA 49. És una peça ASC relacionada que
concreta, en un lloc de la Cerdanya i amb un síndic identificat, com es
negociava la treta de blat entre les declaracions de 1631 i el privilegi de
1646.
