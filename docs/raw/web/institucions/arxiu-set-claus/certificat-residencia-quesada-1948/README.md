# Una resident de Bacares és certificada a Grenoble

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05645 com un certificat de
residència expedit el **16 de novembre de 1948** pel comissari de policia de
**Grenoble** a favor de **Maria Josepa Quesada**, de **Bacares** (Almeria).

La imatge identifica la data de naixement, la filiació i el domicili de
Grenoble, on el certificat indica que residia des del **10 de maig de 1947**.
És una prova administrativa d’una trajectòria migratòria concreta; no permet
determinar el motiu del trasllat ni la relació de Quesada amb Andorra més enllà
de la seva conservació en l’Arxiu de les Set Claus.
