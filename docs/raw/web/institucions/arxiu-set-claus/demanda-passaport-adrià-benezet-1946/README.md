# Una sol·licitud de passaport des de Besiers

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05638 com una carta
d’**Adrià Benezet** al síndic general en què demana la concessió del passaport
andorrà. La carta està datada el **16 de març de 1946** i el catàleg la situa a
**Besiers**.

La imatge mostra que la petició adjunta o anuncia documentació justificativa,
entre aquesta un certificat de residència, una fotografia i un certificat o
acta d’estat civil. La font documenta una tramitació individual, però no
conserva aquí la resolució del síndic ni permet saber si el passaport va ser
concedit.
