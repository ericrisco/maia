# El Consell paga el lloguer i el salari de l’apotecari, 1820

Aquest paquet reuneix dos rebuts del **16 de maig de 1820**:

- **ASC-00637:** rebut del pagament del lloguer de la casa de l’apotecari,
  efectuat pel Consell de les Valls; la fitxa identifica Francisco Dalleres;
- **ASC-00639:** rebut d’**Ot Duran** pel pagament del seu salari com a
  apotecari, efectuat pel Consell General.

Les dues peces estan classificades com a pagaments i apotecaris. Documenten una
part material del servei: el Consell assumia tant la remuneració professional com
l’espai on vivia o treballava l’apotecari.
