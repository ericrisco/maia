# Concòrdia sobre passatge i pasturatge a Santa Cecília, 1543

La fitxa pública d’**Arxius en Línia** descriu l’ASC-3670 com una concòrdia feta
el **14 de gener de 1543** entre els canonges del Capítol de l’església de
**Santa Maria de Castellbò** i els representants de les Valls d’Andorra,
**Gervasi Moles** i **Bernat Rossell**. L’acord tracta el **passatge** i el
**pasturatge** per les terres de Santa Cecília, a Castellbò.

És una font posterior a les ordinacions de 1340 sobre el trànsit de ramats i
permet seguir el problema en una forma diferent: no una queixa contra oficials,
sinó una concòrdia amb una institució eclesiàstica propietària o gestora de les
terres descrites pel catàleg.
