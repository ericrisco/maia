# Un certificat parroquial d’Antònia Rispal

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05685 com un certificat de
residència expedit el **27 d’agost de 1956** per **Daniel Espot Bergés**, cònsol
major d’Andorra Escaldes, a favor d’**Antònia Rispal Guitart**.

La còpia certifica la nacionalitat andorrana, identifica el passaport número
**3.699** i declara que la titular resideix a la parròquia. És una mostra de la
documentació local que acreditava residència i nacionalitat alhora; no permet
reconstruir la mobilitat concreta de Rispal ni l’ús administratiu posterior del
certificat.
