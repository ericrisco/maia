# El nunci Pau Serra demana una rebaixa de salari, 1840

La fitxa pública d’**Arxius en Línia** descriu una súplica de **Pau Serra**, nunci
d’Andorra, adreçada al Consell General i referida a la **rebaixa del seu salari**.
La peça està datada el **14 de desembre de 1840**, té dos folis i està
classificada entre les peticions i súpliques.
