# Un nomenament al Col·legi de Foix, 1672

Les fitxes públiques d’**Arxius en Línia** conserven dues peces de **1672** sobre
**Joan Francesc Sucarà** i el **Col·legi de Foix**. El **20 de març**, l’ASC-4505
recull el nomenament del rei **Lluís XIV de França**, copríncep de les valls
d’Andorra, per cobrir una vacant al col·legi. El **8 de setembre**, l’ASC-4506
recull el manament del mateix rei atorgant a Sucarà una plaça com a col·legiat.

Les dues fitxes documenten el circuit d’un nomenament educatiu vinculat al
coprincipat francès. No permeten saber quins estudis cursava Sucarà ni si el
segon manament executava exactament la vacant del primer.
