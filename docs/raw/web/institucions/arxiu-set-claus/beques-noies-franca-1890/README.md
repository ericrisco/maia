# Beques franceses per a dues noies andorranes, 1890

Aquest paquet reuneix cinc unitats de la sèrie d’ensenyament que documenten la
concessió de beques a dues estudiants andorranes:

- **ASC-05732** (24/09/1890): el delegat Bonhoure comunica que el Govern francès
  ha acordat dues beques i apunta Besiers com a possible destinació;
- **ASC-05733** (16/10/1890): el delegat rep l’acord del Consell que designa el
  col·legi de Besiers;
- **ASC-05734** (12/11/1890): còpia del decret del president de la República que
  preveu anualment dues beques per estudiar magisteri a França;
- **ASC-05736** (17/12/1890): còpia del decret que atorga les beques a **Maria
  del Pilar Maestre** i **Concepció Huguet**;
- **ASC-05737** (27/12/1890): Bonhoure notifica al síndic que les beques han estat
  concedides.
