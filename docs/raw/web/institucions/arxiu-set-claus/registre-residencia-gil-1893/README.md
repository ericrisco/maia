# Un andorrà s’inscriu al registre municipal francès

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05604 com l’acta
d’inscripció de **Josep Isidre Gil Vigatà**, d’Encamp, al registre de residència
de **Puègserguièr**. El document és un extracte francès d’immatriculació en
aplicació de la llei del 8 d’agost de 1893, datat el **12 d’octubre de 1893**.

La fitxa i la imatge registren el lloc de naixement a Encamp i la nacionalitat
andorrana. La peça mostra un tràmit municipal francès de residència d’un veí
andorrà, però no permet reconstruir per si sola la durada de l’estada ni el
motiu complet del desplaçament.
