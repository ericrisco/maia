# Ordinacions sobre pastures i pas del bestiar, 1340

La fitxa pública d’**Arxius en Línia** descriu l’ASC-3545 com un trasllat
autoritzat per **Pere Sicard**, notari públic de Castellbò, d’unes ordinacions
donades per **Roger Bernat de Castellbò** entre el **26 de gener i l’1 d’abril
de 1340**. El text respon a la súplica de Ramon de l’Ortell i «Camulleni»
Rossell de Canillo, que el catàleg vincula amb el procurador dels homes d’Andorra, i també a
requeriments anteriors de Gastó II de Foix i dels mateixos andorrans.

Segons el catàleg, la finalitat era regular les **pastures** i el **pas del
bestiar andorrà per l’Urgell**, i posar fi a les extorsions que els oficials
infringien als ramaders. La peça conservada és un foli de pergamí amb el recto
manuscrit i el verso majoritàriament en blanc, amb marques i anotacions del
suport.
