# Súplica del síndic per treure sal de Cardona, 1520

La fitxa pública d’**Arxius en Línia** descriu l’ASC-3913 com una súplica del
síndic de les valls d’Andorra, datada el **5 de juliol de 1520**, que demana dos
mesos per poder treure sal de les salines de Cardona segons un contracte ja
establert i no executat a causa de la guerra.

La peça té **2 folis** i està classificada en l’àmbit de comerç, amb els
 descriptors **sal**, **importació** i **súpliques**. El catàleg situa el document
entre les salines de Cardona i Barcelona.
