# Una ordre de 1691 mobilitza animals per portar malalts a l’hospital

La fitxa pública d’**Arxius en Línia** descriu l’ASC-3615 com una carta del
**6 d’agost de 1691** del veguer de Cerdanya i comissari subdelegat de
l’intendent Trobat, **Sr. Sicart**, als batlles i consellers d’Andorra. L’ordre
exigeix que proporcionin cavalcadures amb albardes i bastons per transportar els
malalts a l’hospital de la Seu d’Urgell.

La peça mostra una obligació logística imposada a les autoritats locals. No
permet saber quants malalts hi havia, qui pagava el transport ni si el servei es
va executar completament.
