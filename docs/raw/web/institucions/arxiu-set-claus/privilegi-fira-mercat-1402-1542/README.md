# Ratificació de la fira anual i el mercat setmanal, 1542

La fitxa pública d’**Arxius en Línia** descriu l’ASC-1289 com la ratificació que
el bisbe d’Urgell **Francesc d’Urries** va fer el **22 d’abril de 1542** d’un
privilegi concedit per **Galceran de Vilanova** el **13 de febrer de 1402**. El
privilegi permetia als homes d’Andorra celebrar **una fira anual i un mercat
setmanal**.

El portal cataloga la unitat com un foli i ofereix una rendició de **dues
pàgines d’imatge**. El recto mostra el document manuscrit amb segell pendent i
el verso, el revers del suport i anotacions. S’han revisat visualment totes dues
cares. L’extracció automàtica no conté text útil.
