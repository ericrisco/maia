# Pactes amb l’apotecari Francesc Balmes, 1737

La fitxa pública d’**Arxius en Línia** descriu l’ASC-04549 com els pactes entre
el **Consell General** i **Francesc Balmes d’Igualada** pel seu servei com a
apotecari a les valls d’Andorra. El catàleg els data **1737 post.**, els
classifica com a contracte i servei sanitari i els descriu com una unitat de dos
folis.

La rendició mostra un document articulat en capítols i una signatura final. La
imatge permet identificar el caràcter contractual i els actors, però no ofereix
una lectura prou segura per transcriure totes les obligacions, preus o durada.
