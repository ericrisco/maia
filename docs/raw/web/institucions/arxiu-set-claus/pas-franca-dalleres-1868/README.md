# Pase de Pere Dalleres para circular por Francia, 1868

La fitxa pública d’**Arxius en Línia** descriu l’acta del **26 de novembre de
1868** que concedeix a **Pere Dalleres**, veí d’Andorra la Vella, un passe de
trasllat dins de França. El document fou atorgat pel batlle **Anton Armengol** i
els síndics **Nicolau Duedra** i **Anton Picart**.

La peça conserva també una declaració de testimonis de Canillo. La imatge mostra
que la petició es presenta com un permís per viatjar i circular pel Regne de
França, però no permet establir quant va durar el passe ni quin viatge concret
va fer Dalleres.
