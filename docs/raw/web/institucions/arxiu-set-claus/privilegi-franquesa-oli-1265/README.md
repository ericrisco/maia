# Privilegi de franquesa del mesuratge d’oli, 1265

La fitxa pública d’**Arxius en Línia** descriu l’ASC-1186 com el privilegi
atorgat el **18 de gener de 1265** pel bisbe d’Urgell **Abril Pérez Peláez** als
homes d’Andorra. La concessió els dona **franquesa del dret de mesuratge d’oli a
la Seu d’Urgell**.

El portal cataloga la unitat com un foli i ofereix una rendició de **dues
pàgines d’imatge**: el recto del pergamí i el verso amb anotacions posteriors.
S’han revisat visualment totes dues pàgines. La primera és una carta medieval en
llatí amb la concessió, la data i la zona de testimonis o validació; la segona
conserva notes posteriors de lectura difícil. L’extracció automàtica no conté
text útil.
