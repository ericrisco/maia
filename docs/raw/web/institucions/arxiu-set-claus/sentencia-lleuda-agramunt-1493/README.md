# Sentència arbitral sobre la lleuda d’Agramunt, 1493

La fitxa pública d’**Arxius en Línia** descriu l’ASC-03783 com la sentència dels
àrbitres barcelonins **Jeroni Lacera, Lluís Salgueda i Joan Mai** en la causa
entre **Pere de Capdevila**, donzell d’Agramunt, i els habitants de les valls
d’Andorra. Després d’examinar diversos documents, la sentència del **30 de juny
de 1493** reconeixia que els andorrans gaudien de franquesa de lleuda a
Agramunt. La sentència fou homologada el 6 d’agost i Capdevila hi presentà un
requeriment el 19 d’agost.

El portal cataloga la unitat com un foli i ofereix una rendició de **dues
pàgines d’imatge**. El recto és un pergamí extens amb el text i signes de
validació; el verso mostra el revers del suport i anotacions posteriors. S’han
revisat visualment totes dues cares. L’extracció automàtica no conté text útil.
