# Una proposta d’escola primària el 1882

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05731 com una proposició de
**Clodovée Papinaud**, delegat permanent francès, que remet a l’aprovació del
Consell General la instal·lació d’una escola primària a Andorra. El catàleg la
data l’**11 de juliol de 1882**, la classifica dins l’ensenyament i la descriu
com una unitat de dos folis.

Les rendicions manuscrites mostren una carta en francès adreçada al Consell. El
text argumenta la proposta a partir de les relacions dels andorrans amb França
i demana que el Consell valori la instal·lació; la font no prova per si sola que
el centre s’arribés a obrir.
