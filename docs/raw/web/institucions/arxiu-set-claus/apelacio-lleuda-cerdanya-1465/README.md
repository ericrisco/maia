# Andorra apel·la contra la lleuda de Cerdanya, 1465

La fitxa pública d’**Arxius en Línia** descriu l’ASC-3781 com l’apel·lació que
**Guillem Aldosa**, en nom dels cònsols i prohoms d’Andorra, presenta davant
**Gabriel Muntaner**, lloctinent del procurador reial al comtat de Cerdanya, a la
taula de Joan d’Urús a Puigcerdà. L’apel·lació s’adreça contra un manament que
obligava els andorrans a presentar documents per poder gaudir de la seva
franquesa de lleuda.

El document, datat entre el **5 d’octubre i el 2 de novembre de 1465**, exposa
les raons de l’exempció i demana que es lliurin apòstols reverencials. La fitxa
afegeix que el 7 d’octubre se’n lliura còpia al lloctinent i que el 2 de novembre
Muntaner rebutja l’apel·lació perquè el manament provenia del seu superior.
