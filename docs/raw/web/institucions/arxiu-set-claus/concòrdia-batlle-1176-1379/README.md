# Trasllat de la concòrdia sobre el batlle d’Andorra

La fitxa pública d’**Arxius en Línia** descriu l’ASC-03660 com un trasllat de la
concòrdia establerta entre el bisbe d’Urgell **Arnau de Préixens**, els canonges
d’Urgell i els homes d’Andorra sobre la funció del batlle i altres qüestions.
El catàleg dona les dates **8 de gener de 1176 – 8 de gener de 1379**, que
distingeixen l’acte traslladat de la data del trasllat.

El portal cataloga la unitat com un foli i ofereix una rendició de **dues
pàgines d’imatge**. El recto és un pergamí molt dens i esvaït; el verso mostra
el revers del suport i restes de text. S’han revisat visualment totes dues cares.
