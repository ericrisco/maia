# Trasllat de la potestat per defensar muntanyes i emprius, 1513

La fitxa pública d’**Arxius en Línia** descriu l’ASC-3663 com un **trasllat de la
potestat** donada per **Pere Arnau de Castellverdú**, veguer d’Andorra pel comte
de Foix, als andorrans perquè poguessin defensar les seves muntanyes i emprius
contra qui els causés perjudici.

El catàleg dona el rang de dates **1 de juliol de 1332 – 17 de setembre de
1513**, un foli i els descriptors muntanyes, emprius, potestat i perjudicis. La
fitxa identifica també **Joan Ortedó**, notari de les valls d’Andorra.
