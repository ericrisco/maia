# Sentència sobre el pont del Grau, 1595

La fitxa pública d’**Arxius en Línia** descriu l’ASC-03801 com una sentència del
**8 de març de 1595** sobre el litigi entre les valls d’Andorra i els cònsols de
la Seu d’Urgell pel pont situat al lloc dit **Grau**, davant el **Quer de Santa
Llúcia**, en el camí de la Seu a Andorra.

El catàleg classifica la peça com a sentència i litigi de reparacions i ponts.
Les cinc pàgines digitalitzades inclouen anotacions i documentació processal,
però aquesta captura de consulta no permet reconstruir el fallo ni repartir
amb seguretat les obligacions de reparació.
