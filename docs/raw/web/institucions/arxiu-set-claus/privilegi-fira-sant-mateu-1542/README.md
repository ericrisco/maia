# Privilegi de fira per Sant Mateu, 1542

La fitxa pública d’**Arxius en Línia** descriu l’ASC-1290 com el privilegi
atorgat el **23 d’octubre de 1542** per **Jaume de Foix**, en nom del comte de
Foix, que autoritza els homes d’Andorra a celebrar una **fira al setembre per la
festivitat de Sant Mateu**.

El portal ofereix una rendició de **dues pàgines d’imatge** d’un foli. El recto
mostra el document manuscrit amb segell pendent i el verso, el revers del suport
amb anotacions. S’han revisat visualment totes dues cares. L’extracció
automàtica no conté text útil.
