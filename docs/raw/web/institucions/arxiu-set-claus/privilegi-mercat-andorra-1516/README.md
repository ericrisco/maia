# Privilegi de mercat quinzenal sense tributs, 1516

La fitxa pública d’**Arxius en Línia** descriu l’ASC-1287 com el privilegi
atorgat el **23 de març de 1516** pel bisbe d’Urgell **Joan Despes** per celebrar
mercat cada quinze dies a la parròquia d’Andorra la Vella **sense pagar tributs
per les mercaderies**.

El portal cataloga la unitat com un foli i ofereix una rendició de **dues
pàgines d’imatge**. El recto conserva el document manuscrit amb un segell i
restes de penjoll; el verso mostra anotacions i el revers del suport. S’han
revisat visualment totes dues cares. L’extracció automàtica no conté text útil.
