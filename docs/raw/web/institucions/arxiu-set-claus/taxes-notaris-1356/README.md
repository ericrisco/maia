# Trasllat de les taxes dels notaris de les Valls, 1356–1357

La fitxa pública d’**Arxius en Línia** descriu l’ASC-5826 com un trasllat
autoritzat per **Guillem de Ministrells**, notari públic de la Seu d’Urgell, de
la regularització de les taxes dels notaris de les Valls d’Andorra feta per
**Guillem Jaculatori d’Ax** i **Roger de Besora**, veguers respectius del comte de
Foix i del bisbe d’Urgell. El catàleg data la unitat entre el **13 de juny de
1356 i el 12 de maig de 1357**.

La peça ofereix una correspondència arxivística directa per a la normativa de
62 capítols que el corpus coneixia per fonts institucionals i bibliogràfiques.
És un trasllat, no necessàriament l’original de la regulació.
