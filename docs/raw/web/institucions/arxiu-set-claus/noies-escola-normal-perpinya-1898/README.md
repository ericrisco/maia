# Correspondència sobre noies andorranes que estudien a Perpinyà

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05741 com una carta
d’**Antoni Huguet** al Sr. Molines, datada el **2 d’abril de 1898**, en què li
envia documentació sobre les noies d’Andorra que estudien a l’**Escola Normal
de Perpinyà**. El catàleg la classifica com a correspondència, estudis i
estudiants, i la relaciona amb Sant Julià de Lòria i Perpinyà.

La rendició manuscrita permet identificar l’emissor, el destinatari, la data i
el tema general de la documentació. No permet fixar amb seguretat els noms o el
nombre de les estudiants.
