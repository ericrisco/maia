# La reclamació dels resultats del cens

La fitxa pública d’**Arxius en Línia** descriu l’ASC-05607 com una carta del
delegat permanent francès **Ardison** al síndic general **Bonaventura Maestre**.
Datada el **18 de desembre de 1896**, pregunta si ja s’ha fet el cens de la
població andorrana que Ardison havia acordat amb el síndic anterior.

És el document de seguiment de la proposta d’agost del mateix any. La carta
confirma que el cens s’havia plantejat com una tasca administrativa concreta,
però aquesta unitat tampoc no incorpora el recompte final ni una taula de
habitants.
