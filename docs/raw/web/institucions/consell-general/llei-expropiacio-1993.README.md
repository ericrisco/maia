# Llei d’expropiació d’Andorra (1993)

Captura textual del PDF oficial de la **Llei d’expropiació**, aprovada el 3 de setembre de 1993 i publicada al BOPA núm. 51 (28-09-1993). La font explica que el règim anterior incloïa un decret de 1958, modificat el 1974, i que el projecte de llei aprovat el 1989 no es va poder promulgar abans de la Constitució.
