# *Estudi preliminar de les actes històriques del Consell General*

Pàgina institucional de **Jordi Guillamet** que descriu el projecte de
transcripció de les actes històriques. Confirma que els llibres IV–XI es poden
consultar digitalment a l’Arxiu Nacional i identifica el **Llibre V (FCV 9485,
1864–1940)**, que conté cronològicament l’any 1934.

La pàgina distingeix entre **digitalització** i **transcripció**: el projecte
posa en marxa la transcripció paleogràfica, però la pàgina d’actes transcrites
publica de moment els llibres antics i no ofereix encara la transcripció del
Llibre V. Per tant, la consulta de l’acta de juliol de 1934 continua depenent de
la digitalització del volum i de localitzar-hi el foli.

No hi consta una llicència específica de reutilització. Es conserven l’HTML i
l’extracció textual per a lectura i citació.
