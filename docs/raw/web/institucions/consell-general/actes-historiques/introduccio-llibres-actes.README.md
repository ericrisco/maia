# *Introducció als llibres d’actes del Consell General*

Pàgina institucional que descriu la sèrie conservada dels llibres d’actes i el
projecte de transcripció. Identifica el **Llibre V, FCV 9485, 1864–1940**, i el
**Llibre VI, FCV 9486, 1940–1961**; indica que els originals es poden consultar
al web de l’Arxiu Nacional d’Andorra.

Aquesta referència és rellevant per a la Constitució de 1934: situa l’acta que
cal revisar dins del Llibre V i dona la signatura arxivística **FCV 9485**. La
pàgina no transcriu la sessió de juliol de 1934 i no permet afirmar encara si la
votació hi consta.

Es conserven l’HTML i l’extracció textual per a lectura i citació. La pàgina no
declara una llicència específica de reutilització.
