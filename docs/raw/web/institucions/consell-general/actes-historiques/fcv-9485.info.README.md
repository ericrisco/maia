# *Llibre d’actes del Consell General, 1864–1940* — FCV 9485

Fitxa pública d’**Arxiu en Línia** per al document `FCV_09485.pdf`. El registre
indica un original de **388.473.856 bytes**, **741 pàgines** i només **200
pàgines visualitzables** en la previsualització pública. La URL confirma la
signatura del volum que conté cronològicament la sessió de 1934, però l’API no
ofereix un índex que permeti mapar l’any 1934 a una pàgina dins les 200
visualitzables.

L’**Estudi preliminar del Consell General** ([font](../../../../../fonts/actes-historiques-estudi-preliminar.md)) confirma que els llibres IV–XI es poden consultar digitalment, però que el projecte de transcripció encara no ofereix el Llibre V. Aquest registre continua sent una prova de localització del volum, no una transcripció ni una prova que l’acta de juliol de 1934 sigui encara llegible a la previsualització pública.

Es conserven l’HTML, l’extracció textual i la resposta JSON de l’API per a
documentar la ruta d’arxiu, el nombre de pàgines i els límits de consulta.
