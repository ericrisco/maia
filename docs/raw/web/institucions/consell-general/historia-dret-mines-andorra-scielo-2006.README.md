Captura textual de l’extracte retornat per la cerca web de l’article acadèmic de la revista *Revista de Estudios Histórico-Jurídicos*. El text localitza una concessió de mines andorrana de 1875 i en resumeix dues clàusules: prohibició de transmetre-la a un estranger i reserva del Consell General per reclamar una part dels beneficis. El text íntegre no s’ha pogut descarregar en aquesta sessió.
