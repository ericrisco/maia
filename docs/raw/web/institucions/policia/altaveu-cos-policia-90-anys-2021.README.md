# *El Cos de Policia compleix 90 anys*

Reportatge de **Bru Noya** (15 de maig de 2021) sobre el primer reglament del
Servei d’Ordre. Reprodueix les missions relatives a l’ordre i a la vigilància
dels estrangers, identifica el cap **Secundí Tomàs Roca** i sis agents, i dona
tres expedients inicials (1932 i 1933).

La peça és periodística i el corpus la conserva només per a lectura i
verificació; les divergències amb el reportatge de *Bondia* s’han mantingut
explícites a la fitxa històrica.
