# Agent del servei d’ordre — registre fotogràfic 22697

Fitxa del catàleg de l’Arxiu Nacional d’Andorra per a un retrat d’un agent del
Servei d’Ordre, datat **1940–1950**. Dona el fons **FAM**, el número de registre
**22697**, el negatiu **4612** i el quadre de classificació **801.6**.

El registre descriu la fotografia però no n’ofereix una còpia descarregable. És
una referència visual primària localitzable, no una identificació del nom de
l’agent.
