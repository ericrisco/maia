# Marc Pantebre Palmitjavila — fons fotogràfic

Fitxa oficial del fons **AD ANA, FPP** al catàleg del Govern d’Andorra. El fons,
amb dates extremes **1931–1973**, conserva una fotografia d’un agent del Servei
d’Ordre, tres imatges dels gendarmes a Canillo i una imatge de les eleccions de
1933. L’accés consta com a **lliure**; la reproducció es regeix pels articles 41
a 53 del Reglament de l’Arxiu Nacional de 2005.

La fitxa no identifica encara l’agent ni dona una còpia de la imatge al corpus:
serveix com a registre d’un testimoni visual primari que es pot demanar a l’Arxiu
Nacional.
