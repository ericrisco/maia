# *Història i Identitat* — Policia d’Andorra

Pàgina institucional de la Policia d’Andorra. Explica que el **Servei d’Ordre**
va ser creat pels veguers l’any **1931**, amb un cap i sis agents, i en descriu
les missions inicials: mantenir l’ordre públic, auxiliar els batlles en la fase
preparatòria dels judicis penals i perseguir i detenir delinqüents.

La font és institucional i contemporània; no reprodueix el reglament de 1931 ni
dona els noms dels agents. El corpus conserva l’HTML per a lectura i verificació.
No hi consta una llicència específica de reutilització.
