# Expedient del canje de notes amb Andorra, 1866–1868

El catàleg de PARES descriu la unitat **ULTRAMAR,4714,Exp.42** de l'Archivo
Histórico Nacional amb el títol «Convenio con los Países Bajos y Canje de notas
con Andorra». La descripció cobreix **1866–1868** i explica que s'hi conserven
quatre exemplars impresos del conveni amb els Països Baixos i quatre del canvi de
notes del **13 de juliol de 1867** amb la Vall d'Andorra.

La mateixa descripció identifica el contingut andorrà: el canvi de notes va
tornar a donar franquícia per introduir a Espanya, lliures de drets, els ramats i
les altres produccions de la Vall. És una **descripció arxivística**, no el text
dels exemplars: en aquesta consulta no s'han recuperat imatges ni una
transcripció de l'expedient.
