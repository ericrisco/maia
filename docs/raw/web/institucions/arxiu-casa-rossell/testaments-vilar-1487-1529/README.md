# Dos testaments de la Cortinada, 1487 i 1529

Les fitxes públiques d’**Arxius en Línia** conserven dos testaments de la Casa
Rossell. L’**CR-180** és el testament de **Ramon Vilar de la Cortinada**; el
catàleg el data entre el **2 d’abril i el 2 de desembre de 1487** i indica que
nomena hereva la seva germana **Maria**. L’**CR-181** és el testament de
**Pere Vilar de la Cortinada**, datat el **18 d’octubre de 1529**.

El primer document s’atribueix al notari **Joan Ortedó** i el segon a
**Nicolau Guiem Ortedó**. Cada unitat és un foli amb dues cares digitalitzades.
La proximitat familiar dels dos testadors és una possibilitat de recerca, però
no es pot donar per provada només amb les descripcions del catàleg.
