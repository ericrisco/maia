# Rebut de Jacques Dandine per comptes de la farga, 1812

La fitxa pública d’**Arxius en Línia** descriu el CR-31892 com un rebut de
**Jacques Dandine**, que es declara satisfet i pagat de tots els comptes amb
**Bonaventura Riba Guillaumes de la Massana**. El catàleg el data el **5 d’abril
de 1812**, el classifica dins de vendes de ferro, rebuts i pagaments, i relaciona
la peça amb Ausat (França) i la farga d’Ordino.

La imatge permet llegir que el rebut es va signar a **Ausat** i que el text
esmenta comptes de fargues i altres comptes. No s’hi ha afegit cap import perquè
el foli no dona una xifra llegible ni una liquidació detallada.
