# Llibre d’enviaments de ferro, 1808

La fitxa pública d’**Arxius en Línia** descriu el CR-31883 com el *Llibre
d’enviaments de ferro de l’any 1808*, conservat al fons **Casa Rossell** i
vinculat a la **Farga Areny** d’Ordino. El catàleg el classifica dins de vendes
de ferro i el descriu com una unitat de set folis.

La digitalització mostra un llibre de detall: hi ha entrades datades, noms de
compradors o destinataris, quantitats i totals anotats al marge. El suport
permet comprovar la funció comptable del llibre, però no s’hi ha afegit una
transcripció completa ni s’han normalitzat els noms i les mesures.
