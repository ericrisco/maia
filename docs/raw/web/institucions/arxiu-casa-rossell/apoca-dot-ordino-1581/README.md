# Una mare i una filla reconeixen un dot, 1581

La fitxa pública d’**Arxius en Línia** descriu el CR-20096 com una **àpoca**
signada el **31 de desembre de 1581** per **Caterina Vidal, vídua, i la seva
filla Maria Vidal d’Ordino**, a favor d’**Antoni Rossell (dit Vidal)**. El
catàleg identifica Antoni com a gendre de Caterina i marit de Maria, i explica
que el document es fa en concepte de dot.

La peça s’atribueix al notari **Joan Colat** i conserva l’acte com un foli de la
Casa Rossell. L’àpoca acredita el reconeixement d’una obligació dotària, però la
fitxa no dona l’import ni descriu els béns lliurats.
