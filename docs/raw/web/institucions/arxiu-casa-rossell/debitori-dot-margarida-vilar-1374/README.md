# Debitori del dot de Margarida Vilar, 1374

La fitxa pública d’**Arxius en Línia** descriu el CR-16197 com el debitori que
**Pere Vilar de la Cortinada** va signar a favor del seu gendre **Ramon de
Soldevila** en concepte del dot de la seva filla **Margarida**. El catàleg el
data el **1374**, el classifica com a document de la **Casa Rossell** i el
registra amb la signatura ANA/CR-16197.

El portal cataloga la unitat com un foli i ofereix una rendició de **dues
pàgines d’imatge**. El recto conserva el text manuscrit i la validació; el verso
mostra un suport molt deteriorat, amb pèrdues i anotacions. S’han revisat
visualment totes dues cares. L’extracció automàtica no conté text útil.
