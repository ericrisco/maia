# *Estimacions de població i censos parroquials, any 2021*

Nota estadística institucional que diferencia la **població registrada** —el
recompte directe dels censos parroquials— de la **població estimada**, calculada
pel Departament d’Estadística encreuant diverses fonts administratives. Inclou
un gràfic de la població d’Andorra per al període **1948–2021**, amb les dues
sèries, i permet situar el salt demogràfic dels anys cinquanta a vuitanta dins
una sèrie oficial més llarga.

El gràfic històric no publica una taula numèrica completa any per any. Per això
no substitueix la taula quinquennal reproduïda a *Joves i llengües d’Andorra*,
però confirma el període cobert i obliga a no barrejar població registrada amb
població estimada. La nota indica com a font les dades tractades dels registres
administratius i no declara una llicència de reutilització.
