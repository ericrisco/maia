# Demografia — nacionalitat i vot a Andorra

## *Nacionalitat i vot* (2004)

- **Font:** Pepita Batalla, *Nacionalitat i vot*, revista *Ciutadans*, núm. 1; còpia allotjada per l'Institut d'Estudis Andorrans.
- **URL:** <https://sociologia.ad/files/401/Articles/1339/Nacionalitat-i-vot-%282004%29.pdf>
- **Fitxer:** [`nacionalitat-i-vot-2004.pdf`](./nacionalitat-i-vot-2004.pdf)
- **Consulta i baixada:** 2026-09-21.
- **Ús al corpus:** documenta la població registrada el 2002 per nacionalitat: **67.159** persones, **25.467 andorranes (37,9 %)** i, per tant, **62,1 % de nacionalitat estrangera**; el gràfic desglossa espanyola (38,8 %), portuguesa (10,0 %), francesa (6,5 %) i altres (6,8 %). La font atribueix les dades al Departament de Treball del Ministeri de Justícia i Interior, *Estadístiques de població any 2002*.
- **Condicions:** còpia d'un article publicat; el lloc no especifica una llicència de redistribució. Es conserva com a font de treball i no es redistribueix ni s'incorpora a cap dataset.
