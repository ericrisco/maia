# Fonts web sobre la Clínica Vilanova

## `dones-invisibles-2020.pdf` / `.txt`

- URL: <https://static1.ara.cat/ara/public/content/file/original/2020/0304/12/estudi-dones-invisibles-d-andorra-de-magda-mata-170a7c2.pdf>
- Publicació: Magda Mata, *Dones invisibles d’Andorra*, 2020.
- Consulta: 2026-09-20.
- Ús: data l'obertura de la Clínica Vilanova el 1944, el primer emplaçament a cal Guillemó i el trasllat de 1954 a l'edifici Molines; també situa la inauguració de la Clínica Verge de Meritxell el 1971.
- Condicions: informe publicat en accés web per *Ara*; termes de reutilització no especificats. Es conserva la còpia local com a font de treball i no es redistribueix ni entra en cap dataset.

## `iec-historia-sanitat-2010.pdf` / `.txt`

- URL: <https://publicacions.iec.cat/repository/pdf/00000169/00000043.pdf>
- Publicació: Rosa Mari Mandicó i Alcobé, «Definició d’un nou model sanitari: creació d’una escola universitària d’infermeria», *XV Jornades: Quina formació per a la vida laboral?*, 2010, p. 123–127.
- Consulta: 2026-09-20.
- Ús: confirmació dels dos emplaçaments —cal Guillemó, plaça Rebés, i casa Molines, damunt del bar del Trèvol— i de les catorze habitacions de la clínica.
- Condicions: publicació de la Societat Andorrana de Ciències; termes de reutilització no especificats. Es conserva la còpia local com a font de treball i no es redistribueix ni entra en cap dataset.
