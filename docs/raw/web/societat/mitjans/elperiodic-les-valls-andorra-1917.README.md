# *Premsa i literatura: Les Valls d’Andorra*

Còpia HTML de l’article de **Josep Carles Laínez**, publicat a *El Periòdic
d’Andorra*. La peça situa el primer número el gener de 1917, identifica Josep
Alemany i Borràs com a fundador, director i propietari, i afegeix que els set
primers números es van reproduir facsimilarment als *Papers de Recerca
Històrica* de la Societat Andorrana de Ciències.

La font distingeix entre la direcció i l’adreça a Barcelona i la impressió a La
Seu d’Urgell, i identifica **Benito Mas** com a signant del primer número.

La pàgina no declara una llicència de reutilització. Es conserva com a font de
treball i no es redistribueix ni entra en cap dataset.
