# Activitat pública del Sindicat Andorrà de Treballadors (SAT), 2020–2021

Fonts locals conservades per comprovar si el SAT continuava actiu:

- [Bondia: El SAT prepara una assemblea per trobar una nova junta i no desaparèixer](./bondia-sat-assemblea-2020.html)
- [El Periòdic d'Andorra: Manifest de l’1 de maig del 2021](./periodic-sat-manifest-2021.html)

La pàgina de Bondia documenta el període d’interinitat del SAT després de la jubilació de Guillem Fornieles i l’assemblea prevista per trobar una nova junta. El manifest d’El Periòdic, signat per Fornieles com a secretari general, documenta activitat pública del SAT l’1 de maig de 2021. Cap de les dues fonts no acredita l’estat de l’organització el 2026.
