# La guerra dels Segadors i Andorra — captura local

Aquesta carpeta conserva el PDF i l’extracció textual de l’article de Domènec
Bascompte i Grau, **«La guerra dels Segadors i Andorra: Pau Claris, canonge de
la catedral de la Seu d’Urgell i el bisbe d’Urgell Pau Duran»**, publicat a
*Conflictes bèl·lics al Pirineu*, 21es Trobades Culturals Pirinenques (2025),
p. 53–71.

La còpia és per a consulta i verificació. L’article és una síntesi secundària:
les dates i els documents que cita s’han de contrastar amb els llibres d’actes,
els privilegis i els arxius que el mateix estudi relaciona.
