poques taules). **Els `.txt` són l'extracció de text i són el que es versiona.**

## Una URL que no existeix, registrada perquè ningú la torni a provar

`https://ca.wikipedia.org/wiki/Llista_de_síndics_generals_d'Andorra` **no
existeix**. L'article català es diu **`Síndic general`** i conté la llista a
dins. **Les llistes angleses són dues i no una**, separades pel 1993.

## Contradiccions detectades, i on estan registrades

Totes van a [la fitxa de font](../../../fonts/wikipedia-politica-andorra.md) i a
les fitxes corresponents. La més greu: **`sindic-general-ca` dona Guillem
d'Areny-Plandolit com a nascut el 19 de febrer de 1882**, quinze anys després
d'haver deixat el càrrec. **El corpus rebutja la lectura i manté 1822.**
