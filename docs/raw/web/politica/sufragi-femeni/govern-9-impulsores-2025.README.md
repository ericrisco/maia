# *Les nou impulsores del sufragi femení* — Govern d’Andorra (2025)

Nota institucional sobre la concessió de l’Orde de Carlemany a les nou
impulsores del sufragi femení. Dona els noms de **Angelina Mas Joaniquet, Maria
Molné Armengol, Bonaventura Coma Riba, Concepció Naudí Areny, Joaquima Calvó
Santuré, Montserrat Jordana Fiter, Paquita Mandicó Riberaygua, Joana Cerdà
Cabanes i Carmen Noguer Enríquez**; les cinc darreres i Bonaventura Coma són
reconegudes a títol pòstum segons la nota.

La nota parla d’unes 400 signatures i diu que Carme Travesset va ser la primera
dona elegida el 1973. La pàgina històrica del Consell General conserva una xifra
precisa de 378 signatures i situa la primera consellera general el 1984 en
substitució i la primera elegida en una legislatura el 1986. El corpus conserva
les dues afirmacions i deixa oberta si «elegida» el 1973 es refereix a eleccions
comunals o a una altra categoria de càrrec.

És una nota commemorativa contemporània, no una font primària de 1967–1973.
