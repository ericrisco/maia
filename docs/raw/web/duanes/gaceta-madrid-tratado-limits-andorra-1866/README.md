# Tractat de límits des d'Andorra fins al Mediterrani, 1866

La *Gaceta de Madrid* núm. 203, publicada el **22 de juliol de 1866**, publica
la llei de **29 de juny** que autoritza ratificar el tractat de límits signat a
Baiona el **20 de maig de 1866** i l'acta addicional. El preàmbul diu que el
tractat completa la frontera oriental «des del Vall d'Andorra fins al
Mediterrani».
