# Cupos de franquícia d'Andorra, 1926

Aquesta carpeta conserva la pàgina 327 de la **Gaceta de Madrid** núm. 20,
publicada el **20 de gener de 1926**. La Reial ordre aplica els articles 2 i 4
del decret de 18 d'octubre de 1922 i fixa les quantitats de franquícia per a
l'any 1926.
