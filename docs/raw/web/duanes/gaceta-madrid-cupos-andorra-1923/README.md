# Cupos de franquícia d'Andorra, 1923

La **Gaceta de Madrid** núm. 119, publicada el **29 d'abril de 1923**, reprodueix
una reial ordre del **23 d'abril** que aplica el decret de 18 d'octubre de 1922.
La pàgina impresa 425 manté per a 1923 els cupos d'exportació que havien estat
assenyalats per a 1922 i fixa els cupos d'entrada de productes andorrans.
