# Real decreto de franquícies d'Andorra, 1922

Aquesta carpeta conserva el número 294 de la **Gaceta de Madrid**, publicat el
**21 d'octubre de 1922**, amb el reial decret de franquícies d'Andorra a les
pàgines impreses **254–255**. El decret està datat a palau el **18 d'octubre de
1922**; la data de publicació i la data de signatura no són la mateixa.
