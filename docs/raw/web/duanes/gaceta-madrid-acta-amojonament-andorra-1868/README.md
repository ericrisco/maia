# Acta final d'amollonament des d'Andorra fins al Mediterrani, 1868

La *Gaceta de Madrid* núm. 51, publicada el **20 de febrer de 1869**, conserva
les disposicions addicionals signades a Baiona l'**11 de juliol de 1868** i
l'**acta final de l'arranjament de límits al Pirineu**. La descripció comença
amb la fita **427**, al pic de Valira, entre França i Andorra, i acaba al tram
mediterrani amb la fita **602**.
