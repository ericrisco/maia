# Cupos de franquícia d'Andorra, 1925

La **Gaceta de Madrid** núm. 28, publicada el **28 de gener de 1925**, reprodueix
una reial ordre del **15 de gener** sobre els cupos sol·licitats per l'Obispado
de Urgel. La pàgina impresa 446 concreta les quantitats d'entrada i sortida
per a aquell any.
