# Restabliment de la franquícia d'Andorra, 1867

La *Gaceta de Madrid* núm. 207, publicada el **26 de juliol de 1867**, dona a
la pàgina impresa **200** les notes canviades el **13 de juliol** entre el
ministre d'Estat espanyol i el president del Consell General del Vall
d'Andorra. El document explica que les ordres de 17 de maig de 1864 i 12
d'agost de 1866 havien suprimit la franquícia per combatre el contraban i que
la restitució es fa per reciprocitat i conveniència mútua.
