# Cupos de franquícia d'Andorra, 1931

La **Gaceta de Madrid** núm. 21, publicada el **21 de gener de 1931**, reprodueix
una reial ordre del **16 de gener**, número 41, sobre la proposta del bisbe
d'Urgell i del **Sindicato General del Principado de Andorra**. La pàgina
impresa 459 concreta els cupos d'aquell any.
