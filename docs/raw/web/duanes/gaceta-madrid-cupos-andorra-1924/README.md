# Cupos de franquícia d'Andorra, 1924

La **Gaceta de Madrid** núm. 60, publicada el **29 de febrer de 1924**, reprodueix
una reial ordre del **21 de febrer** sobre la proposta de cupos de l'Obispado de
Urgel. La pàgina impresa 1060 concreta les quantitats per a aquell any.
