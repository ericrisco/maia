# Tres versions de la Llei 92/2010 d'horaris comercials

Instantànies del [Portal Jurídic del Principat d'Andorra](https://portaljuridicandorra.ad/L2010092_F), segons la fitxa de situació de la llei:

| Versió | Data de la fitxa | Text |
| --- | --- | --- |
| Original | 20-01-2011 | [`original.txt`](./original.txt) |
| Text refós 1 | 09-09-2011 | [`refos-1.txt`](./refos-1.txt) |
| Text refós 2 | 11-07-2013 | [`refos-2.txt`](./refos-2.txt) |

La comparació mostra que el **refós 1** incorpora la reforma de la **Llei 7/2011** —entre altres canvis, l'horari general de 7 a 22 h i el límit de 84 hores setmanals— i que el **refós 2** incorpora la reforma de la **Llei 12/2013**, que afegeix les botigues de conveniència de benzinera a l'exempció de l'article 4.5.

**Proveniència:** registre intern a `02-DOCS/raw/sources/portal-juridic-llei-92-2010-versions.md`.
