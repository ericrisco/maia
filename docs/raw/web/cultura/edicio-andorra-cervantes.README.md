# La edición en Andorra — EDI-RED, captura local

Aquesta carpeta conserva la captura HTML i l’extracció textual de la pàgina
**La edición en Andorra**, del portal EDI-RED de la Biblioteca Virtual Miguel de
Cervantes.

La font ofereix una panoràmica editorial, no un catàleg bibliogràfic exhaustiu.
La captura és una còpia de treball per verificar dates, editorials i títols; no
autoritza a redistribuir-ne el text complet.
