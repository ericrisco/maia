# El catarisme a les valls d’Andorra — Carles Gascón Chopo (2009)

- [PDF de l’article](./gascon-el-catarisme-a-les-valls-dandorra-2009.pdf)
- [Text extret del PDF](./gascon-el-catarisme-a-les-valls-dandorra-2009.txt)

L’article revisa les hipòtesis de Ventura i Baraut, el Memorial dels danys, la protecció dels comtes de Foix i el cas documentat del càtar andorrà Ramon Boer. La conclusió manté que la qüestió és problemàtica i que les evidències són escasses, però situa el debat historiogràfic i les fonts.
