# Fonts web sobre oficis i indústries desapareguts d'Andorra

- URL: <https://www.govern.ad/documents/d/guest/2017_els_hostes_oficis_i_industries_desapareguts>
- Publicació: Govern d'Andorra, *Els hostes: oficis i indústries desapareguts*, 2017.
- Consulta: 2026-09-20.
- Ús: identificació i descripció dels oficis tradicionals vinculats a la fusta (picadors, tiradors, serradores i fusters), la pedra (mestres de cases, forns de calç, llosers, tosquers i terrissaires) i altres oficis, entre els quals el baster.
- Condicions: publicació institucional; termes de reutilització no especificats. Es conserva la còpia local com a font de treball i no es redistribueix ni entra en cap dataset.
