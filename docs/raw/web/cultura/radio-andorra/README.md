# Fonts web sobre Ràdio Andorra i la radiodifusió

## `govern-radio-andorra-2011.pdf` / `.txt`

- URL: <https://www.govern.ad/documents/d/guest/2011_els_hostes_lincroyable_aventure_de_radio_andorra>
- Publicació: Govern d'Andorra, *L'incroyable aventure de Radio Andorra*, 2011.
- Consulta: 2026-09-19.
- Ús: verificació dels contactes de Jacques Trémoulet amb els nazis, l'acusació posterior d'intel·ligència amb l'enemic i espionatge, la condemna a mort posterior a l'alliberament, la col·laboració amb l'administració franquista i la cessió estratègica de Radio Andorra a l'Estat espanyol.
- Condicions: publicació institucional; termes de reutilització no especificats. Es conserva la còpia local com a font de treball i no es redistribueix ni entra en cap dataset.

## `govern-radiodifusio-andorra.html` / `.txt`

- URL: <https://www.govern.ad/ca/l/4522687>
- Publicació: fitxa bibliogràfica del Govern d'Andorra, amb el resum de *La radiodifusión en Andorra: política, economía y espacio comunicacional en un país dependiente*.
- Consulta: 2026-09-19.
- Ús: contrastar la seqüència institucional: suport del govern espanyol a la defensa de Radio Andorra, negociació franco-espanyola, acusació de col·laboracionisme i absolució posterior.
- Condicions: pàgina institucional; termes de reutilització no especificats. Es conserva com a metadada i extracte de treball.
