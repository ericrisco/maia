# *L'incroyable aventure de Radio Andorra*

Publicació institucional del Govern d’Andorra conservada en PDF i text extret a
`docs/raw/web/cultura/radio-andorra/`. El capítol **«Radio Andorra durant la
guerre»** descriu el silenci informatiu de l’emissora, les pressions alemanyes i
de Vichy, les acusacions de col·laboració amb els Aliats i la condemna posterior
de Jacques Trémoulet i altres responsables.

La font és una narració divulgativa institucional: dona la seqüència i les
referències internes, però no reprodueix les ordres ni els expedients originals.
El corpus conserva la còpia de treball i no en redistribueix el contingut
íntegre.
