# Una màquina llevaneu Ford a Andorra (1936)

La fitxa pública d’**Arxius en Línia** titula aquesta fotografia **«Primera màquina llevaneu d’Andorra»** i la data a la **tardor de 1936**. El catàleg atribueix la imatge a **Joan Vehils**, la conserva dins del seu fons i descriu un **camionet Ford amb remolc i una pala incorporada**.

La fotografia conservada mostra el vehicle amb la pala muntada en un camí de muntanya. La localització exacta no consta a la fitxa i no s’infereix de la imatge.
