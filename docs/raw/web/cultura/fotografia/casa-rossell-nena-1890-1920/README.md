# Una nena al pati d’una casa (1890–1920)

La fitxa pública d’**Arxius en Línia** descriu la fotografia CR_0011 com un **retrat d’una nena al pati d’una casa**, amb un gerro sobre un tamboret al seu costat. El catàleg l’atribueix a **J. Andreu**, la data entre **1890 i 1920** i la conserva al **fons Casa Rossell**.

La imatge permet veure la roba, el posat i part de l’espai domèstic, però no dona el nom de la nena, la casa, la parròquia ni la data exacta. Aquest README conserva la descripció sense convertir una escena anònima en una identificació personal.
