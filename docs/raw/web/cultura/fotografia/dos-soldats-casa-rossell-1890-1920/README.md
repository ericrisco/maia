# Dos soldats en un grup al bosc (1890–1920)

La fitxa pública d’**Arxius en Línia** titula CR_0015 **«Soldats»** i descriu una instantània d’un grup assegut a la vora d’un camí al bosc, amb **dos soldats**. El catàleg la data entre **1890 i 1920**, l’atribueix a **Joaquim de Riba Camarlot** i la conserva al fons Casa Rossell.

La imatge mostra el grup en un espai boscós. No identifica els soldats, el seu exèrcit, el lloc, la data exacta ni el motiu de la trobada.
