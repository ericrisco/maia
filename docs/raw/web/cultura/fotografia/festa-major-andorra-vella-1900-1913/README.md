# Una plaça decorada a Andorra la Vella (1900–1913)

La fitxa pública d’**Arxius en Línia** titula CR_0027 **«Festa Major a Andorra la Vella»**, però descriu l’escena com una celebració d’un acte festiu **possiblement** relacionat amb la Festa Major. El catàleg la data entre **1900 i 1913**, l’atribueix a **Joaquim de Riba Camarlot** i hi identifica garlandes a la plaça i llençols als balcons.

La imatge mostra una plaça decorada, persones reunides, arbres ornamentals i les façanes dels edificis. No fixa el dia, l’ocasió exacta ni el lloc més enllà de la identificació catalogràfica d’Andorra la Vella.
