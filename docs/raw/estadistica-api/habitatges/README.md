## Habitatges acabats, no permisos

**La divisió 188 i les seves set germanes per parròquia compten habitatges
per tram de superfície i per any.** **El corpus les llegeix com a habitatges
acabats i no com a permisos concedits**, i **no ha trobat la sèrie de permisos
a l'API.** `Sense les dues sèries no es pot mesurar quant de temps passa entre
demanar i acabar.`

## «Superfície mitjana per permís» és una altra cosa

**Les divisions 152-157 donen la superfície mitjana per permís** —general,
d'habitatge i de xalet, amb desglossament per parròquia—. **No són el mateix
que la distribució d'habitatges per tram de superfície** (188-195), i **el
corpus no les barreja.**
