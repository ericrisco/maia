| `1` | Població registrada total | 1947–2025 | 79 |
| `1100` | Població per edat (trams d'1 any) | 2010–2025 | 1.600 |
| `1098` | Població per sexe i edat (trams de 5 anys) | 2010–2025 | 576 |
| `1099` | Població per edat (trams de 5 anys) i nacionalitat | 2010–2025 | 1.440 |

La sèrie de divisió `1100` té edats de 0 a 98 anys i una categoria oberta
`DE 99 ANYS O MÉS`; per tant, no permet distingir separadament les edats de
99, 100 o més anys. La divisió `1098` usa una categoria oberta de 85 anys o
més; no s'ha de confondre amb la classificació d'un any d'edat. La divisió
`1099` registra cinc nacionalitats/grups per edat quinquennal.

Aquestes captures són una instantània datada, no una consulta en temps real.
Les taules contenen distribucions agregades per període; no identifiquen ni
segueixen persones individuals i no determinen causes de canvi, país de
naixement, moment d'arribada o via d'adquisició de nacionalitat.
