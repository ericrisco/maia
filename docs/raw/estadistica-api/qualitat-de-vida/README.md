## Dos avisos de lectura

1. **La formació contínua salta de 2,4% (2023) a 9,8% (2024)**, un factor de
   quatre en un any. **El corpus no ho llegeix com un canvi real** sense una
   nota metodològica que no s'ha trobat. `Registrat i no citat com a
   tendència.`
2. **Diverses divisions repeteixen el mateix total** sota noms de taula
   diferents —`PER EDAT. TOTAL`, `SEGONS EL NIVELL D'EDUCACIÓ. TOTAL`,
   `SEGONS LA NACIONALITAT. TOTAL`—. **És el mateix valor vist des de
   desglossaments diferents**, no tres mesures.
