## El desglossament per sexe només hi és a tres taules

**De les vint divisions, només tres es desglossen per sexe**: qui té
responsabilitats de cura (2064), de quin col·lectiu (2066) i quantes hores
treballa qui fa servir serveis de cura (2071).

**Les tres preguntes on la desigualtat es veuria** —qui ha deixat la feina
almenys un mes (2079), quant de temps (2080) i qui ha reduït l'horari per
familiars dependents (2082)— **donen només el total.** **Registrat com a buit**
a [la llei d'igualtat](../../../temes/societat/dones/la-llei-digualtat.md).

## Un sol any

**No és una sèrie.** Tot el que hi ha és **2018**, i qualsevol comparació amb
avui hauria de venir d'una altra font.
