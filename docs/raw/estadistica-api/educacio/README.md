## No hi ha guarderies

**La branca compta la maternal**, que és **escola**. **El tram de 0 a 3 anys no
hi surt**, ni en places ni en centres. **Registrat a
[les guarderies](../../../temes/societat/educacio/les-guarderies.md).**

## Els centres es nomenen per parròquia o per nom propi

**La divisió 259 (maternal per centres) barreja dues coses**: **deu entrades
amb nom de parròquia o de poble** —Canillo, Encamp, Pas de la Casa, Ordino, la
Massana, Andorra la Vella, Santa Coloma, Sant Julià de Lòria,
Escaldes-Engordany— i **cinc amb nom propi de centre** —Sant Ermengol,
Col·legi Janer, Sagrada Família, Col·legi dels Pirineus i The British College
BCA—.

**La font no diu quins són públics, concertats, congregacionals o privats.**
**El corpus no ho dedueix del nom.**

## «Estudiants escolars» és el no universitari

**La divisió 1387 dona el total del país** —**11.259 el curs 2024**— i inclou
**maternal, primària, secundària, batxillerat i formació professional**.
**Els universitaris i els estudiants no universitaris a l'estranger tenen
divisions pròpies** (1405 i següents).
