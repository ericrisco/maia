## Un defecte de nomenclatura, comprovat

**A la divisió 1096 (població per poble), la parròquia de Sant Julià de Lòria
apareix amb dos noms diferents**: **el cap de parròquia porta `(SANT JULIÀ)`**
i **els altres nou pobles porten `(SANT JULIÀ DE LÒRIA)`**. **Qui agrupi per
l'etiqueta entre parèntesis obtindrà vuit parròquies en comptes de set.**

## «Població per poble» són 44 entrades

**No són tots els nuclis habitats del país**: **són els 44 que la font
identifica.** **Andorra la Vella hi surt amb dues entrades** —Andorra i Santa
Coloma— i **Escaldes-Engordany amb una de sola.**

## Les xifres són de padró

**És la població registrada**, no l'estimada. **Les dues sèries existeixen i no
donen el mateix** ([qui compta com a resident](../../../temes/societat/demografia/qui-compta-com-a-resident.md)).
