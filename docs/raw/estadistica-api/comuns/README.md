## Tres pressupostos diferents per al mateix any

**Cada comú té tres parells de línies**, i **no són la mateixa cosa**:

| Sèrie | Què és |
| --- | --- |
| **Pressupost de l'exercici** | el de l'any, ingressos i despesa |
| **Pressupost de gestió** | drets i obligacions reconeguts |
| **Pressupost de caixa** | cobraments i pagaments |

**El corpus cita el «pressupost de l'exercici»** i ho diu cada vegada.

## Els pressupostos estan quadrats per construcció

**Ingressos i despesa de l'exercici són idèntics** per als set comuns el 2026 i
per a gairebé tots els anys de la sèrie. **El «resultat pressupostari previst»
és, doncs, zero per definició**, i **no és una mesura de superàvit.** **El
superàvit o el dèficit real és a les sèries de liquidació** (`02020206`), **que
aquest bolcat no inclou.**

## Les xifres anteriors al 2002 són conversions

**La sèrie arrenca el 1990**, quan la moneda eren pessetes i francs. **Els
valors surten en euros amb cèntims** —`1.059.343,94` el 1990 a Canillo—, cosa
que **indica conversió i no import original.** **El corpus cita les xifres
antigues com a ordres de magnitud**, no com a imports exactes.
