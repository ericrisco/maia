# Pla i Programa estadístics

Tres peces del BOPA baixades el **17 de setembre del 2026**: la **Llei 27/2025,
de l'11 de desembre, del Pla d'estadística 2026-2029**, el **Decret 25/2026,
del 21-1-2026, d'aprovació del Programa estadístic anual 2026** i la **correcció
d'errata del 28-1-2026**.

**Per què importen.** El Programa anual conté **el catàleg complet de codis
d'activitat** del Departament d'Estadística. Aquests codis són el que permet
localitzar les notes de premsa del Departament, que es publiquen amb el patró
`sig.govern.ad/SIGDDE.Public/Files/Documents/Notes_premsa_noticies/<CODI>_<DATA>_A.pdf`
i que el cercador no indexa completament. **Sense el catàleg, cada sèrie
estadística s'havia de buscar a cegues.**

`catalog-activitats-2026.md` és la taula extreta amb script del text del decret.
