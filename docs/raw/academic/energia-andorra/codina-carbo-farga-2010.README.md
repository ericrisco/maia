# *El carbó vegetal i la farga a Andorra*

Article d'Olivier Codina i Vialette sobre l'ús del carbó vegetal, els primers
indicis arqueològics de treball del ferro, el dret de carbonar i la relació entre
els boscos, els ferrers i les fargues andorranes.
