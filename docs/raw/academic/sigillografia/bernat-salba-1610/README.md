# Ferran de Sagarra — *Sigil·lografia catalana*, volum III

Volum digitalitzat de Ferran de Sagarra, publicat per l’Ajuntament de Barcelona
el 1932 i consultat el **23 de setembre de 2026**. El catàleg descriu el segell
de fra Bernat de Salbà i identifica el pergamí del bisbe que confirma els
privilegis de les Valls.

- `sigillografia-catalana-inventari-segells.pdf` — còpia del volum III.
- `sigillografia-catalana-inventari-segells.txt` — extracció amb
  `pdftotext -layout`.

A la pàgina impresa **82**, entrada **3407**, el catàleg descriu un segell rodó
de 45 mm, de cera vermella en capsa de llauna, conservat a l’Arxiu de les
Valls, Armari-calaix 18. Indica que penja, per cintes de seda groga i vermella,
d’un pergamí en què el bisbe confirma els privilegis de les Valls, datat a **30
d’octubre de 1610**. La font és una descripció sigil·logràfica, no una
transcripció del pergamí.
