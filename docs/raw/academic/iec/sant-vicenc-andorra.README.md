# La disgregació del món ibèric a la Vall d’Andorra — captura local

Aquesta carpeta conserva el PDF i una extracció textual de l’article de Josep
Maria Bosch i Casadevall, publicat a *Papers de recerca històrica* 2 (2004),
p. 10–18. La còpia és per a consulta i verificació; no autoritza a redistribuir
el text complet.

L’article sintetitza els resultats arqueològics del Roc d’Enclar i proposa que la
construcció de Sant Vicenç, entre la fi del segle VII i el començament del VIII,
podia ser una manifestació de poder episcopal o eclesiàstic.
