# *Carlemany i Andorra — Història de la Carta Pobla*

Paquet de la recerca d’Oliver Vergés sobre la **Carta Pobla** o **Fals de
Carlemany**:

- la pàgina de projecte d’**Andorra Recerca + Innovació** presenta la recerca i
  llegeix el document com una falsificació medieval;
- el PDF de l’**Institut d’Estudis Andorrans** conserva l’estudi complet, amb
  transcripció, crítica diplomàtica, recorregut historiogràfic i una hipòtesi
  sobre el context de fabricació i ús del document.
