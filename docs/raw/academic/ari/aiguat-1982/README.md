# *Aiguats del 1982 — Andorra Recerca i Innovació i ICGC*

Paquet de fonts institucionals sobre l’episodi del 6–8 de novembre de 1982:

- la notícia d’**Andorra Recerca i Innovació** resumeix la modelització
  meteorològica, l’informe de danys del Govern i la resposta d’emergència;
- la monografia de l’**Institut Cartogràfic i Geològic de Catalunya**, capítol
  2.3, descriu l’episodi regional d’esllavissades i les afectacions a Andorra.
