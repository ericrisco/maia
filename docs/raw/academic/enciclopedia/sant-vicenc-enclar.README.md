# Sant Vicenç d’Enclar (Andorra la Vella) — captura local

Aquesta carpeta conserva una captura HTML i una extracció textual de l’article
**Sant Vicenç d’Enclar (Andorra la Vella)** de l’*Enciclopèdia Catalana*.
La captura serveix com a còpia de treball i com a registre de la consulta; no és
una nova edició de l’article ni autoritza a redistribuir-ne el text.

La font descriu la situació estratègica del puig, la seqüència documental del
castell i les excavacions del conjunt de l’església, l’hàbitat i la necròpolis.
També adverteix que la reconstrucció moderna fa que alguns detalls visibles avui
no siguin íntegrament originals.
