# *Els refugiats “andorrans” de la Guerra Civil Espanyola — Una aproximació*

Article de **Gerhard Lang-Valchs**, publicat per la **Societat Andorrana de
Ciències** dins *Andorra, país de pas i de refugi* (2016). Estudia els fugitius
que entraren a Andorra entre juliol de 1936 i gener de 1939, separant les dades
documentades de les extrapolacions.

Memòria Històrica de Salamanca i altres fons. És una publicació acadèmica en
accés obert; no consta una llicència específica de redistribució.
