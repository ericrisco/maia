# Camp Vermell i els orígens de Sant Julià

Abel Fortó García i Àlex Vidal Sánchez estudien el jaciment de Camp Vermell dins
el volum de 2009 sobre les aldees altmedievals europees. El PDF local és el
volum complet; l'article ocupa les pàgines impreses **253–262**.

## Abast del passatge

L'article documenta una seqüència d'ocupació entre els segles **II i XII dC**:
un espai d'hàbitat i una tomba (fase I, II–IV), un conjunt de sitges i un
taller metal·lúrgic (fase II, V–VII), i dues cabanes, quatre tombes i un camí
pavimentat (fase III, VIII–XII). Els autors proposen relacionar aquesta
ocupació recurrent amb la *villa Lauredia* documentada a inicis del segle X,
però adverteixen que el registre pot correspondre a una ocupació semidispersa o
discontínua.
