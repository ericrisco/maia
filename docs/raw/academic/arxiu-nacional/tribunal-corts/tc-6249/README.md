# Expedient TC-6249 del Tribunal de Corts

Paquet de consulta del registre digital de l’**Arxiu Nacional d’Andorra**.
El registre de FotoWeb el descriu com: **«Acusada de bruixeria: Joana Tora»**. El registre indica l’any
**1621** i conserva **7 pàgines** de previsualització.

La fitxa corresponent del cercador d’*Andorra, Terra de Bruixes* resumeix
l’expedient, però aquesta carpeta conserva la referència primària i les imatges
públiques per poder separar el resum editorial de la lectura manuscrita.

Al darrer foli visible es llegeix el nom **Joana Tora de Bixesarri**, la seva
no compareixença després de citacions i la fórmula de **contumàcia**. La pena
econòmica no es dona per llegida en aquesta còpia.
