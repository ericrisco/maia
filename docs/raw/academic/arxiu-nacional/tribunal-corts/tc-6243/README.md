# Expedient TC-6243 del Tribunal de Corts

Paquet de consulta del registre digital de l’**Arxiu Nacional d’Andorra**.
El registre de FotoWeb el descriu com: **«Acusada de bruixeria: Joana Naudina Àlies Busqueta»**. El registre indica l’any
**1621** i conserva **5 pàgines** de previsualització.

La fitxa corresponent del cercador d’*Andorra, Terra de Bruixes* resumeix
l’expedient, però aquesta carpeta conserva la referència primària i les imatges
públiques per poder separar el resum editorial de la lectura manuscrita.

Una diligència visible està encapçalada per una data que es llegeix com **26
d’octubre de 1621**. La carpeta no en presenta una transcripció completa.

- `tc-6243.asset-response` — resposta JSON de FotoWeb amb metadades i
  l’enllaç a les pàgines.

  pàgina.

el registre ofereix públicament.
