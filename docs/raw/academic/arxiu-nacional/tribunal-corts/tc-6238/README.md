# Expedient TC-6238 del Tribunal de Corts

Paquet de consulta del registre digital de l’**Arxiu Nacional d’Andorra** per
a l’expedient **TC-6238**. El cercador de *Andorra, Terra de Bruixes* enllaça
aquest codi amb **Maria Galoxa àlies Palanco** i també amb **Petronil·la
Peyrona**. La fitxa JSON de FotoWeb porta com a descripció «Acusada de
bruixeria: Peyrona Rufona», mentre que la coberta manuscrita de la primera
pàgina llegeix «De Maria Galoxa» i porta el codi manuscrit TC-6238.

La discrepància es conserva expressament. Aquest paquet no decideix si es
tracta d’un expedient amb diverses persones, d’una remissió creuada del
catàleg o d’una descripció que cal corregir.

## Fitxers

- `tc-6238.info.html` — pàgina pública del registre.
- `tc-6238.asset-response` — resposta JSON de l’API de FotoWeb, amb metadades,
  permisos i l’enllaç a les pàgines.
- `page-01.asset.json` … `page-17.asset.json` — metadades JSON de cada pàgina.
- `page-01-2400px.jpg` … `page-17-2400px.jpg` — vistes prèvies locals de les
  disset pàgines, descarregades des de les previsualitzacions del registre.

## Lectura mínima segura

- La coberta identifica manuscritament **Maria Galoxa** i el codi **TC-6238**.
- Una anotació interior és datada manuscritament el **16 de juny de 1621**;
  la lectura de la data és paleogràfica i es manté com a tal.
- Les pàgines contenen un expedient manuscrit de causes de bruixeria, però la
  cal·ligrafia i la marca d’aigua no permeten extreure’n aquí una transcripció
  fiable sense una lectura paleogràfica completa.

No es redistribueix el PDF original: el paquet conserva només les previsualitzacions
que el registre ofereix públicament i les respostes de consulta necessàries per
reproduir-ne la procedència.
