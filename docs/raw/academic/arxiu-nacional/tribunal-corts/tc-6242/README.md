# Expedient TC-6242 del Tribunal de Corts

Paquet de consulta del registre digital de l’**Arxiu Nacional d’Andorra**.
El registre de FotoWeb el descriu com: **«Acusada de bruixeria: Jaumina Fustera»**. El registre indica l’any
**1621** i conserva **8 pàgines** de previsualització.

La fitxa corresponent del cercador d’*Andorra, Terra de Bruixes* resumeix
l’expedient, però aquesta carpeta conserva la referència primària i les imatges
públiques per poder separar el resum editorial de la lectura manuscrita.

Les diligències visibles inclouen una fórmula datada **«vigesima septima Junii
1621»** i una altra del **23 d’octubre de 1621**. La carpeta no en presenta una
transcripció completa.

## Fitxers

- `tc-6242.info.html` — pàgina pública del registre.
- `tc-6242.asset-response` — resposta JSON de FotoWeb amb metadades i
  l’enllaç a les pàgines.
- `page-01.asset.json` … `page-08.asset.json` — metadades de cada
  pàgina.
- `page-01-2400px.jpg` … `page-08-2400px.jpg` — previsualitzacions
  locals descarregades del registre.

No es redistribueix el PDF original. Les imatges són les previsualitzacions que
el registre ofereix públicament.
