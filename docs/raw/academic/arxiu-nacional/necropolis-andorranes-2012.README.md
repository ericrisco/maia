# Les necròpolis andorranes (2012)

Article d’Abel Fortó García, Xavier Maese Fidalgo i Àlex Vidal Sànchez publicat
a *Arqueologia funerària al nord-est peninsular (segles VI–XII)*, Monografies
d’Olèrdola 3.1 (MAC, 2012), p. 221–235. La còpia consultada és la versió
completa visible a ResearchGate; el corpus conserva la referència, la URL i una
síntesi pròpia, no una redistribució del text íntegre.

## Passatges utilitzats

El treball descriu el Camp del Perot (39 tombes excavades, 42 inhumats, 47
estructures documentades), el Camp Vermell (quatre enterraments dispersos) i
l’hort de l’Església de la Massana. Les 13 datacions de radiocarboni del Camp
del Perot situen l’ús de la necròpolis entre **710 i 1135 cal AD** amb un 95 %
de confiança.

La conclusió metodològica és central: la variació formal de les tombes no permet
ordenar-les automàticament en una seqüència cronològica. Els tipus poden
coexistir i, al Camp del Perot, els autors observen una associació estadística
entre el tipus antropomorf i els homes i entre les cistes i les dones, però no
una exclusivitat.
