# El Roc d’Enclar com a comunitat rural (1997)

Article de Maria Àngels Ruf, Cristina Yáñez, Xavier Solé, Toni Vila, Xavier
Llovera i Josep Maria Bosch, publicat als *Annals de l’Institut d’Estudis
Gironins*, vol. XXXVII (1997), p. 1131–1143. És una peça complementària a la
monografia del mateix any i permet citar directament el marc de recerca sobre la
comunitat rural del Roc d’Enclar entre els segles IV i VIII.

El corpus conserva la referència i la URL de RACO, però no redistribueix el text
íntegre. Les dades de camp i la periodització es contrasten amb la fitxa del
Govern d’Andorra i amb la monografia de 1997.
