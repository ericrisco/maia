# Valor del punt de jubilació, 2009-2026

**19 decrets** baixats del **BOPA** el **2026-09-17** amb l'API pública. Un
fitxer per data de publicació.

El Govern fixa cada gener, per decret i en aplicació dels **articles 200 i 201 de
la Llei 17/2008 de la seguretat social**, dos valors: el **preu de venda del
punt** —el que val un punt quan es cobra la pensió— i el **preu de compra del
punt** —el que costa acumular-ne un—. L'actualització es fa **vista la variació
percentual de l'IPC** de l'any anterior.

La sèrie destil·lada és a
[La via preferent](../../../../temes/societat/sanitat/la-via-preferent.md).

**Drets.** El BOPA és el diari oficial i no porta avís de reserva de drets. **Cap
document no conté dades personals.**
