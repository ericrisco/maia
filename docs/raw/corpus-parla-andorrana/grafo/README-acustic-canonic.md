# Graf acústic agregat del corpus canònic

Aquesta capa resumeix els **60 parlants canònics** a partir de 656 clips acústics i 451 tokens amb formants. Hi ha 57 nodes amb mesures i la resta conserva el node sense inventar valors. Cada node mesurat conserva medianes de F0, F1, F2, F3, pausa i proporció de veu. Les **1036 arestes** tenen almenys quatre dimensions disponibles i distància euclidiana z ≤ 1,35.

La columna `formes_compartides_asr` només indica coincidències textuals potencials. La distància és una semblança instrumental agregada, no una atribució dialectal ni una prova de veu compartida. Cal escolta abans d'interpretar cap relació.
