# Candidats fora del recompte canònic

Aquest directori conserva fonts noves que encara no entren a `persones.tsv` ni al
metagraf principal. Cada candidat ha de passar identificació, separació de veus,
termes d'ús, transcripció i auditoria abans d'incorporar-se com a persona
canònica.

En conjunt hi ha **11 expedients**, **124 clips locals** i **371 files de formes**. La taula [`auditoria-candidats.md`](../auditoria-candidats.md) i el [reproductor complet](../auditoria-candidats-completa.html) mantenen la revisió separada del registre canònic. La [primera cua prioritària](../cua-audicio-candidats-prioritaria.md) cobreix una mostra inicial de 20 clips i les 11 veus; el [reproductor específic](../auditoria-cua-candidats-prioritaria.html) permet anotar-la i exportar-la sense tocar el cànon. La [auditoria d'integritat](../auditoria-integritat-transcripcions-candidats.tsv) confirma que els 124 clips tenen WAV i doble ASR local.

presentador; hi ha una clusterització acústica provisional, però no s'ha assignat cap clúster a Joan i per això no es compta entre les 60 persones canòniques.
