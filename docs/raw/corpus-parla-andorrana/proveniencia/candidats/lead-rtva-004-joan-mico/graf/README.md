# Graf provisional — Joan Micó

Aquesta vista manté el candidat RTVA separat del graf canònic. Usa **12 formes** presents en small i base i connecta Joan Micó amb **60 persones** que en comparteixen almenys dues segons la matriu ASR completa.

Les arestes són semblances textuals; no indiquen dialecte, identitat lingüística ni veu confirmada. Joan Micó no entra encara al recompte canònic.
