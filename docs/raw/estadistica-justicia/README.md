## Les xifres del 1r trimestre del 2026

**55 reclusos** en un centre de **153 places** (**35,9% d'ocupació**); **52
homes i 3 dones**. Per nacionalitat: **altres 23**, **espanyola 13**,
**andorrana 12**, **portuguesa 7**. Per delicte, la punta és **drogues amb 12**.

**19 condemnes** al trimestre, **14 de tres mesos o menys**, **cap de més de tres
anys**. **27 ingressos**.
