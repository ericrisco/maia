Acord entre l'Usuari i SAAS - Servei Andorrà d'Atenció Sanitaria
El lloc web SAAS consta de vàries pàgines web funcionant a SAAS.
El lloc web SAAS s'us ofereix condicionat a la vostra acceptació sense modificacions de les condicions i avisos inclosos aquí. L'ús del lloc web SAAS constitueix el vostre contracte amb tots aquestes condicions i avisos.
Modificació de les condicions d'Ús
SAAS - Servei Andorrà d'Atenció Sanitaria es reserva el dret de canviar les condicions i avisos sota els quals s'ofereix el lloc web SAAS, incloent però no limitant-se als càrrecs associats amb l'ús del lloc web SAAS.
Enllaços a llocs de tercers
El lloc web SAAS pot contenir enllaços a altres llocs web ("Llocs enllaçats"). Els Llocs enllaçats no estan sota el control de SAAS i SAAS no es fa responsable dels continguts de cap Lloc enllaçat, incloent sense cap limitació tots els enllaços continguts en un Lloc enllaçat, o qualsevol canvi o actualització del Lloc enllaçat. SAAS no és responsable dels webcasting o de qualsevol altra forma de transmissió rebuda de qualsevol Lloc enllaçat. SAAS proporciona aquests enllaços només per motius de comoditat, i la inclusió de qualsevol enllaç no implica que SAAS aprovi el lloc o tingui cap associació amb els seus operadors.
Cap ús ilegal o prohibit
Com a condició del vostre ús del lloc web SAAS, heu de garantir a SAAS que no usareu el lloc web SAAS per cap finalitat que sigui il·legal o estigui prohibida per aquests termes, condicions i avisos. No podeu fer servir el lloc web SAAS de cap forma que pugui malmetre, desactivar, sobrecarregar o perjudicar el lloc web SAAS o interferir amb l'ús de tercers del lloc web SAAS. No podeu obtenir o intentar obtenir cap material o informació amb mitjans que no s'hagin posat a disposició o proporcionats de manera intencionada pel lloc web SAAS.
