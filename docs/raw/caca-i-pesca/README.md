localitzades el 18-09-2026 al `20250325` i al `20250808` amb el sondeig del
patró d'URL sobre la finestra 2024-06-01 → 2025-09-30
([README del sondeig](../estadistica-sondeig-2024/README.md)). **Cap de les dues
no conté dades**: totes dues remeten a `www.govern.ad`.

## Comprovacions fetes

- **Les cinc taules de l'informe de pesca sumen exactament el total imprès, els
  cinc anys**: tipus de llicència de temporada, edats, llicències turístiques
  per tipus, per modalitat de venda i permisos d'acotat. **Vint files de total,
  vint quadrades.**
- **El «92,1% d'andorrans i residents» del resum surt de sumar només les dues
  files retolades així** (81 + 1.090 de 1.271). **Les sis llicències de granotes
  i les onze Conava no hi són classificades**; amb elles la proporció és 93,5%.
  **Registrat, no corregit.**
- **La taula 3 de l'informe de caça està desalineada**: títol «del període
  2021-2025» i columnes retolades **2017, 2018, 2019, 2020, 2021**. **No se
  cita.**
- **L'informe de caça dona tres dates d'actualització diferents** dins el mateix
  document —8-5-2025, 9/6/2026— per a plans encara vigents. Registrat.
