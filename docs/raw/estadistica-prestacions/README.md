## La unitat de recompte són quatre, i no una

Això és el que cal fixar abans de citar cap xifra d'aquestes notes. L'A052 de
l'any 2024 en dona quatre de diferents per al mateix ajut:

| | 2024 |
| --- | --- |
| **Sol·licituds presentades** | **107** |
| **Resolucions favorables** | **71** (66,4%) |
| **Llars beneficiàries** | **64** |
| **Persones beneficiàries** | **139** |

**Import mitjà per llar: 5.229,75 €** (−9,4% respecte del 2023). **Les dones són
el 67,6%** dels ajuts; **les llars d'un sol adult** —unipersonals i
monoparentals— **en sumen el 56,3%**.
