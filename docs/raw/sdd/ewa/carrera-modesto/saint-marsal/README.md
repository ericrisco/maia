# Saint-Marsal — censos i accés als arxius dels Pirineus Orientals

Consulta: 12 de setembre de 2026.

Les Archives départementales des Pyrénées-Orientales indiquen que els censos
de població de 1836 a 1936 estan indexats nominalment a FranceArchives pel
projecte Socface. Això converteix el cens de Saint-Marsal de 1936 en una font
prioritària per situar Modesto Carrera Ramon abans de la detenció de 1944.

Fonts:

- <https://www.ledepartement66.fr/les-inventaires-en-ligne/>
- <https://www.ledepartement66.fr/lesarchivesenligne/>
- consulta preparada a FranceArchives:
  <https://francearchives.gouv.fr/fr/basedenoms_recensement?es_names=Carrera&es_forenames=Modesto&es_locations=Saint-Marsal&fulltext_facet=>

`francearchives-carrera-modesto.html` només conté una redirecció de protecció
JavaScript; no és una pàgina de resultats i no permet afirmar ni presència ni
absència. La pàgina oficial departamental també avisa que l'accés als arxius
en línia està temporalment bloquejat per a internautes residents a
l'estranger. Cal reprendre la consulta per una via admesa o presencial, sense
interpretar el bloqueig com un resultat arxivístic.
