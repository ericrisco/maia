homologació administrativa com a deportat o internat de la Resistència; no
permet atribuir-li una organització o activitat concreta sense obrir el
dossier. El SHD informa que `GR 16 P` pot contenir actes d'engagement, estats
de serveis, certificats de pertinença i citacions.

La resta de fragments CSV, duplicats dins el ZIP original, i els metadades
`__MACOSX` s'han retirat després de verificar la fila per no versionar uns 290
MB redundants. La font completa continua preservada al ZIP.

La pàgina oficial permet reutilitzar les dades amb menció de l'origen i la
data d'actualització. Els documents de l'SHD mantenen les seves condicions
pròpies i no s'han de convertir automàticament en corpus d'entrenament.
