# Arolsen `8060800` — localització pendent de descàrrega

Catàleg públic:
<https://collections.arolsen-archives.org/en/document/9915202>.

La sèrie descriu 96 documents d'arribades a Dachau des dels annexos de
Natzweiler entre el 12 i el 17 d'abril de 1945. La descripció diu que les
llistes contenen noms, números de presoner, dates de naixement, oficis i tipus
de detenció, i enumera Bisingen, Calw, Dautmergen, Dormettingen, Erzingen,
Frommern i Geisheim.

El servidor esgotà repetidament el temps de connexió el 12/09/2026. No s'ha
acceptat automàticament cap declaració de consentiment ni s'ha interpretat el
bloqueig com una absència de Carrera. Aquest README conserva la localització i
el límit de la consulta; les imatges continuen pendents.
