# Transmissió web primerenca del registre Carrera

Captura: 12 de setembre de 2026.

`victimas-guerra-civil-2009-09-05.html` conserva una llista derivada publicada
el 5 de setembre de 2009. La fila diu:

`CARRERA | Modesto | 20/12/1910 | St-Marcel (?) | Dachau | 74159 | Buchenwald`

La pàgina declara haver extret les dades de l'antic lloc de Bernard Teyssès,
`bteysses.free.fr/pages_temoignages_espagnol.htm`. Els JSON CDX i les captures
HTML de Wayback documenten la migració de la llista a
`/espagne/liste_espagnole.htm`: la versió llegible de 2002 encara no conté
Carrera i la captura de 2004 protegeix el codi font. Els HTML petits amb nom
`bteysses-liste-*` són respostes fallides de rutes candidates i es conserven
perquè els CDX permetin auditar què es va provar.

El valor del conjunt és de crítica de transmissió: mostra `Saint-Marsal`
desplaçat a una columna interpretada com a lloc de naixement i una ruta mínima
Dachau–Buchenwald. No és una font primària ni prova la cronologia posterior.

Les pàgines són còpies de treball de contingut web de tercers, subjectes als
drets dels seus autors i proveïdors. No emprar com a corpus d'entrenament.
