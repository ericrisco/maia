## El patró d'accés, per a properes tandes

Les notes de premsa del Departament es publiquen a
`https://sig.govern.ad/SIGDDE.Public/Files/Documents/Notes_premsa_noticies/<CODI>_<DATA>_A.pdf`,
on `<CODI>` és el codi d'activitat del Pla d'estadística —A001 estimacions de
població, A047 distribució de la renda, A090 previsions macroeconòmiques, A142
IPC— i `<DATA>` el dia de publicació en format AAAAMMDD. **El cercador no indexa
totes les notes**; les seccions temàtiques del portal són la via per trobar-ne el
codi.
