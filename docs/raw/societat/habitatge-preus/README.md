# `docs/raw/societat/habitatge-preus/` — els preus del lloguer, en xifres del Govern

Presentació del **projecte de llei del règim jurídic aplicable als contractes
d'arrendament d'habitatge prorrogats fins al 2027**, Andorra la Vella,
**gener-febrer del 2026**, dotze pàgines. És la peça que dona **els preus
absoluts del lloguer andorrà** que el corpus buscava.

Les fonts que el document cita per a cada xifra: **Departament d'Estadística
(2024)** per als 25.000 contractes, **SICAR** per al preu mitjà de 13,5 €/m² i
