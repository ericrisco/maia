# `docs/raw/societat/ensenyament-espanyol/` — els convenis educatius amb Espanya

Tres peces del BOPA baixades el **17 de setembre del 2026**: el **Conveni
Hispano-Andorrà en matèria educativa de l'11 de gener del 1993**, el **Conveni
entre els governs d'Andorra i d'Espanya ratificat el 17 de maig del 2007** i
**l'edicte que en fixa l'entrada en vigor el 10 d'octubre del 2007**.

Junts documenten **qui signa cada vegada**: el 1981 Espanya i la Mitra d'Urgell
(acord que el Butlletí no publica), el 1993 Espanya, la Mitra i el Govern andorrà,
i el 2007 només els dos estats.
