# Carta Pobla / Fals de Carlemany

- **Font consultada:** pàgina de projecte d’Andorra Recerca + Innovació i PDF de
  l’estudi d’Oliver Vergés Pons, *Carlemany i Andorra: Història de la Carta
  Pobla, el document que va originar una llegenda* (IEA, 2018).
- **Proveniència:** còpia del PDF oficial descarregada de `iea.ad`; text extret
  amb `pdftotext -layout`; hashes al README de
  `docs/raw/academic/ari/carta-pobla-2018/`.
- **Resultat:** nova font `ari-carta-pobla-2018` i nova fitxa sobre el fals
  diplomàtic, la hipòtesi de datació als segles XI–XII i els usos historiogràfics
  del document.
- **Límit registrat:** la fitxa no tracta el fals com a prova de la fundació
  carolíngia i deixa oberta la consulta del pergamí original i la identificació
  del falsificador.
