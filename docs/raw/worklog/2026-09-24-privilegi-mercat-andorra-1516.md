# Privilegi de mercat quinzenal sense tributs, 1516

## Troballa

La fitxa pública de l’**ASC-1287** descriu el privilegi atorgat per Joan Despes,
bisbe d’Urgell, el 23 de març de 1516 per celebrar mercat cada quinze dies a la
parròquia d’Andorra la Vella sense pagar tributs per les mercaderies.

## Canvi al corpus

S’ha descarregat la rendició original, conservat el JSON de metadades i revisat
visualment les dues pàgines del foli, inclosos el segell i el penjoll. S’hi han
afegit la font ASC-1287 i una fitxa de l’antic règim relacionada amb el mercat
quinzenal documentat per ASC-1286 el 1512.

## Límit

El manuscrit no ofereix OCR útil, transcripció diplomàtica ni traducció. L’article
només afirma els elements descrits al catàleg; les taxes concretes, els productes,
els beneficiaris i la relació jurídica amb el privilegi de 1512 queden oberts.
