# Concurs per museïtzar l'antic centre emissor de Ràdio Andorra

Notícia del **Govern d'Andorra**, publicada el **8 de maig de 2024**.

El Govern explica que convoca un concurs per contractar una empresa que
museïtzi l'antic centre emissor de Ràdio Andorra a Encamp amb realitat
augmentada. El projecte ha d'explicar la història de l'emissora a partir de
l'espai exterior, la sala dels emissors i els espais annexos. La notícia diu
que **l'objectiu, un cop implementat el projecte, és incorporar l'espai de
memòria a l'oferta museística i obrir-lo a tots els públics**.

La notícia no documenta una obertura el 2015 ni confirma que el projecte s'hagi
acabat.
