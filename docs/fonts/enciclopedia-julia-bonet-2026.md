# Gran Enciclopèdia Catalana — Júlia Bonet i Fité

Júlia Bonet i Fité (1922–2011) va obrir una perruqueria als disset anys, el
1939; el 1969 obrí una perfumeria, el 1987 fundà Perfumeries Júlia i el 2004
inaugurà el Museu del Perfum amb la col·laboració del Govern.
