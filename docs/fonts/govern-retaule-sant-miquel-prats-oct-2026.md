# Govern d'Andorra — noves descobertes del retaule de Prats

La peça del mes d'octubre de 2026 descriu la documentació de l'Arxiu Costa
estudiada per Alberto Velasco. La font acredita una taula de coronament que
abans no s'identificava, detalla el procés de venda el 1926 i explica que les
fotografies històriques permetran fer una reproducció del retaule. No s'hi
redistribueix el text ni les imatges originals.
