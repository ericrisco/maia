# *Trasllat de la potestat per defensar muntanyes i emprius, 1513 — ASC-3663*

Font primària digital del fons de l’Arxiu de les Set Claus. El catàleg presenta
la peça com un trasllat notarial d’una potestat concedida als andorrans per
defensar els seus espais d’ús davant perjudicis.

La cronologia de la font separa l’acte atribuït a 1332 del trasllat de 1513. La
fitxa no permet determinar si el trasllat copia l’original, una còpia intermèdia
o una fórmula resumida.
