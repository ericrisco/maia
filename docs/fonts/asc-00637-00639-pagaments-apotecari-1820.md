# *El Consell paga el lloguer i el salari de l’apotecari, 1820 — ASC-00637 i ASC-00639*

Fonts primàries digitals del fons de l’Arxiu de les Set Claus. Els dos rebuts
mostren que el Consell finançava alhora la remuneració d’un apotecari i el lloguer
de la seva casa.

El paquet no conté una transcripció dels rebuts ni permet reconstruir el servei
sanitari sencer. Serveix com a prova de la despesa institucional i de la
presència d’un apotecari dins l’administració de 1820.
