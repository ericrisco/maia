# Informes de capacitat de càrrega màxima parroquial

## Procedència i lectura

- **Origen:** portal institucional del Govern d'Andorra, secció de Territori i Urbanisme.
- **Consulta i captura:** 2026-09-21; notícia publicada el 03-06-2026.
- **Peça exacta utilitzada:** el Govern diu que ha informat sis estudis —els de totes les parròquies excepte Escaldes-Engordany— i que els plans d'urbanisme comunals hauran d'incorporar els preceptes dels estudis un cop aprovats pels comuns.
- **Límit:** la notícia no conté els set POUP, les seves versions consolidades ni les regles que s'apliquen a cada parcel·la.
