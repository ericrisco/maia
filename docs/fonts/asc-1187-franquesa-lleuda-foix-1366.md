# Una còpia tardana d’una franquesa de lleuda

La fitxa d’**Arxius en Línia** atribueix el privilegi ressenyat a **Gastó III de
Foix, Phebo**, el data el **1366** i el descriu com una franquesa de lleuda a les
muntanyes de Foix a favor dels habitants d’Andorra. L’ASC-1187 és l’extracte
conservat, no el document original: el catàleg el situa al segle XVII i no li
assigna data pròpia.

La pàgina manuscrita permet confirmar la naturalesa de còpia i la referència
catalogràfica, però no ofereix OCR útil ni una transcripció publicada. La font és
per tant una pista primària sobre la transmissió d’un privilegi comercial, no una
edició del text de 1366.
