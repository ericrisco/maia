# FMA — Qui som

## Què hi busca el corpus

**La Federació Motociclista d'Andorra (FMA)**, citada a
[el campionat de trial](../temes/esports/altres-esports/el-campionat-de-trial.md)
sense cap fitxa: quan es crea, quanta gent hi ha federada, quines
altres competicions organitza.

## Què en treu

**Creada el 1985**; **afiliada a la Federació Internacional de
Motociclisme (FIM) el 1987.**

**Sis presidents** al llarg de la seva història; l'actual és **Joan
Patrick Lasmolles Pisanu.**

**Set clubs de motociclisme** operen sota el seu paraigua.

**Disciplines organitzades**:

| Disciplina | Detall |
| --- | --- |
| **Trial** | **26 Campionats del Món** organitzats |
| **Enducross** | Via clubs afiliats, dins el campionat nacional |
| **Enduro sobre gel** (Ice Gladiators) | **10 edicions des del 2016** |
| **Supermoto** | **3 Campionats del Món** |
| **Enduro** | **Campionat del Món el 2011** |

**També ha organitzat Campionats d'Europa de trial i de supermoto.**

**`parcial`**: **la font no dona el nombre actual de federats.**
