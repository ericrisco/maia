# Arxiu Diocesà d’Urgell — fitxa institucional

La Generalitat registra l’ADU a la Seu d’Urgell, amb documentació dels segles
XIV–XX i una via pública de contacte per demanar consulta. La fitxa confirma on
cal dirigir la col·lació dels documents de Guitart que les fonts secundàries
citen; no substitueix l’inventari ni l’accés presencial.
