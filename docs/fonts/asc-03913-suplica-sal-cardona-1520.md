# *Súplica del síndic per treure sal de Cardona, 1520 — ASC-3913*

Font primària digital del fons de l’Arxiu de les Set Claus. La fitxa de catàleg
identifica una petició de la sindicatura andorrana relacionada amb l’extracció i
l’entrada de sal de Cardona en un context de guerra.

La font local conserva la descripció oficial i una previsualització, però no una
edició del text. Les conclusions sobre el contracte, el conflicte bèl·lic i la
resolució s’han de mantenir obertes.
