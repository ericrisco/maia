# La butlla de Silvestre II de 1001

- [PDF local](../raw/web/historia/crbmc-butlla-silvestre-ii-1001.pdf),
  [transcripció](../raw/web/historia/crbmc-butlla-silvestre-ii-1001.txt).
- La fitxa identifica la peça com un **privilegi papal de Silvestre II al bisbe
  Sal·la**, escrit **en llatí sobre papir**, datat el **1001**, procedent de
  l'**Arxiu Capitular d'Urgell** i exposat al **Museu Diocesà d'Urgell**.
- El document confirma les possessions de l'Església urgellenca i concedeix el
  privilegi d'immunitat. La font no transcriu íntegrament la butlla.
