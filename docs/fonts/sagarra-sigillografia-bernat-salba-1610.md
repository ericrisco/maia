# El segell de Bernat de Salbà (1610)

Ferran de Sagarra descriu, a l’entrada **3407** de la pàgina impresa **82**, el
segell de fra Bernat de Salbà: rodó, de 45 mm i de cera vermella en capsa de
llauna. El catàleg el situa a l’Arxiu de les Valls, Armari-calaix 18, i diu que
penja d’un pergamí pel qual el bisbe confirma els privilegis de les Valls, datat
a **30 d’octubre de 1610**.

La fitxa documenta el segell i la relació amb el pergamí, però no ofereix la
transcripció del text ni permet col·lacionar físicament la numeració antiga amb
la signatura contemporània **ASC 1104** de l’Inventari de l’Arxiu de les Set
Claus.
