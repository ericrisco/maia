# Govern d'Andorra — Ràdio Andorra, un relat coral

La cronologia situa Victòria Zorzano a l'emissora des del 27 d'abril de 1940,
distingeix Maria Escrihuela com la primera locutora documentada, i data
AndoRàdio el 1958, el pic Blanc el 1964 i el tancament de 1981.
