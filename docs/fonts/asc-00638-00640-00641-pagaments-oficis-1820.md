# *El Consell paga el nunci i l’advocat, 1820 — ASC-00638, 00640 i 00641*

Fonts primàries digitals del fons de l’Arxiu de les Set Claus. Els tres rebuts
permeten seguir una petita sèrie de remuneracions de l’oficial de justícia i de
l’assessorament jurídic del Consell durant 1820.

No hi consta una transcripció dels rebuts ni els imports. La font documenta la
despesa i els càrrecs, no encara el règim laboral o les funcions completes.
