# Primer Campionat Absolut d'Andorra

El GEVA afirma que **el 1965 es va fer el primer Campionat Absolut d'Andorra**;
la FEVA es va fundar posteriorment, el **7 de novembre de 1967**. La font no
desglossa els campions de les edicions anteriors a l'any 2000.
