# Decret 355/2024 — Reglament del CVPC

Text complet del reglament que desenvolupa el Cos de Voluntaris de
Protecció Civil.

## Per què no dona una xifra

**Perquè el reglament decideix explícitament no fixar-ne cap.** L'article
8.3 diu que el nombre de voluntaris es fixa **any a any per ordre
ministerial**, «per garantir un creixement sostenible». **Cap ordre
d'aquest tipus s'ha trobat encara al BOPA.**
