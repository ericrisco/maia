# El sufragi femení andorrà

Aquesta font institucional permet seguir la cadena **1967 → 1968 → 1969 →
1970 → 1973**: iniciativa de set dones, 378 signatures, informe favorable al
vot, decret de sufragi actiu i reconeixement posterior de l’elegibilitat.
