# *Beques franceses per a dues noies andorranes, 1890 — ASC-05732–05737*

Fonts primàries digitals del fons de l’Arxiu de les Set Claus. Les cinc unitats
formen una seqüència de correspondència i decrets que va de la demanda del
Consell General a la notificació final de les beques.

La seqüència permet identificar les dues beneficiàries i el projecte de formació
de magisteri, però no substitueix la lectura íntegra dels decrets ni dels
expedients educatius.
