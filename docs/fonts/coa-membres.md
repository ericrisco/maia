# Membres del COA (2024-2028)

Directori oficial del COA amb el representant de cada federació esportiva
andorrana pel cicle 2024-2028.

## Per què val tant

**Perquè respon d'un sol cop la mateixa pregunta que el corpus repetia a
desenes de fitxes**: qui presideix cada federació. **No dona fundació ni
mida**, però converteix un «cap fitxa de cap federació» en un nom concret
per a gairebé totes.
