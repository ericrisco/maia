# PIRAGUA — usos i tensions de l'aigua a Andorra

  descripció, dates 2018–2021, equip, llicència CC BY 4.0 i enllaç a l'E4.7.
- [Informe E4.7 en PDF](../raw/web/territori/piragua-e47-recursos-hidrics-andorra.pdf)
  i [text extret](../raw/web/territori/piragua-e47-recursos-hidrics-andorra.txt).
- [Nota d'AR+I sobre la neu com a recurs](../raw/web/territori/ari-neu-recurs-hidric.txt),
  que identifica l'estimació satel·litària del *snow water equivalent* del
  26 de març de 2023.

## Lectura delimitada

L'E4.7 té 86 pàgines. S'han destil·lat les pàgines 1–4, 13–16, 24–29,
43–50, 56–63 i 86, amb comprovació de les taules 3 i 16 i de les figures 16–17.
El model usa el 2019 com a any base de les demandes, 220 litres/persona/dia
per al sector domèstic i 207.919 + 345.291 + 729.857 + 210.606 m³ per a les
quatre estacions de neu. El text explica l'origen i les limitacions de les
dades i no converteix captació en neu produïda.
