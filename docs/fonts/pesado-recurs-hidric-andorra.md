# El recurs hídric d'Andorra i el canvi climàtic

Ponència de **Cristina Pesado i Pons** (doctoranda a l'**ObSA**), **Marc Pons i
Pons** i **Juan-Ignacio López Moreno** (**IPE-CSIC**), a la **29a Diada
Andorrana** (2016).

## Per què val

Per **el que declara que no existeix**: el **2016**, tres investigadors del ram
escriuen que **no hi ha cap estudi científic sobre el canvi climàtic i el recurs
hídric d'Andorra**. Això data un buit.
