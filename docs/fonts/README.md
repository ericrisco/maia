# Índex de fitxes de fonts del corpus

Una fitxa per FONT, no per document. Cinquanta articles del mateix fons referencien la mateixa fitxa.

> Branca buida. El contingut arriba a la fase 2 (`temes/`) i a la fase 3 (`parla/`),
> amb investigació profunda i la font citada a cada afirmació.
