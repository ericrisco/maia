# *Manaments de Foix sobre presos i immunitat a Andorra*

Fonts primàries digitals del fons de l’Arxiu de les Set Claus. Les fitxes
identifiquen dues unitats de dos folis sobre l’ordre del governador de Foix i
una còpia de 1512 incorporada a la descripció.

La diferència entre el camp de data del catàleg (1595) i la data de la còpia
(1512) no es resol aquí. Cal consultar els folis complets i la cadena de còpies
abans de construir una cronologia jurídica.
