# Sis fitxes sobre el telègraf entre França, Andorra i la Seu, 1882–1897

Font primària digital del catàleg de l'Arxiu de les Set Claus. Les sis fitxes
permeten seguir, a escala de correspondència institucional, les línies i les
negociacions del telègraf; no substitueixen la lectura paleogràfica dels folis.
