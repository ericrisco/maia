# Consell General — composició actual

## Què hi busca el corpus

**Auditar la composició nominal actual dels 28 escons** del Consell General,
buit de [El Consell General](../temes/institucions/consell-general/el-consell-general.md).

## Què en treu

La pàgina institucional actual confirma que el parlament compta amb **28
consellers i conselleres generals** i publica la llista nominal completa. La
Sindicatura hi apareix encapçalada per **Carles Ensenyat Reig**, síndic general,
i **Sandra Codina Tort**, subsíndica general; la resta de consellers hi són
enumerats individualment.

La font és una pàgina de composició institucional, no una acta electoral: no
permet reconstruir per si sola el procediment de les dues votacions.
