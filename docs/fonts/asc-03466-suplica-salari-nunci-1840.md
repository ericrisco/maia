# *El nunci Pau Serra demana una rebaixa de salari, 1840 — ASC-03466*

Font primària digital del fons de l’Arxiu de les Set Claus. La fitxa identifica
una petició laboral d’un nunci al Consell General.

La font permet documentar la negociació del salari com a assumpte institucional,
però no la quantia, els arguments ni la decisió final.
