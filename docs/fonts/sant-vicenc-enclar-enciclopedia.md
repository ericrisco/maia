# Sant Vicenç d’Enclar

Fitxa de síntesi sobre l’església i el conjunt arqueològic del puig d’Enclar.
La font permet relacionar les restes d’hàbitat, les tombes i la documentació del
castell, però no permet tractar com a segura una única data de fundació de
l’església.
