# El bisbe confirma el mercat i n’eximeix les mercaderies

La fitxa d’**Arxius en Línia** identifica l’ASC-1287 com el privilegi que el
bisbe **Joan Despes** va atorgar el **23 de març de 1516** per celebrar mercat
cada quinze dies a la parròquia d’Andorra la Vella sense pagar tributs per les
mercaderies.

El PDF és un escaneig de les dues cares d’un foli amb segell i restes de
penjoll. No hi ha transcripció ni traducció. La font permet fixar la concessió,
la periodicitat, el lloc i l’exempció fiscal descrits al catàleg, però no les
clàusules completes ni la forma d’aplicació.
