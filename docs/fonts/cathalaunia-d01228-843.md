# Fons Cathalaunia, Documentia D01228

Fitxa descriptiva i transcripció del precepte de Carles datat el 25 de gener
del 843. La metodologia del [Fons Cathalaunia](https://cathalaunia.org/Documentia/Documentia)
presenta aquests textos com a versions orientatives, no com a edicions
crítiques; la fitxa indica que no conserva l'original. No s'ha localitzat una
llicència de reutilització, de manera que aquesta resta pendent.
