# Una concòrdia regula el pas dels ramats, 1543

L’**ASC-3670** és una concòrdia del **14 de gener de 1543** entre el Capítol de
**Santa Maria de Castellbò** i **Gervasi Moles** i **Bernat Rossell**, que hi
actuen per les Valls d’Andorra. La fitxa concreta l’espai: les terres de Santa
Cecília, a Castellbò.

El document mostra una via negociada per ordenar el **passatge** i el
**pasturatge**. Llegit al costat de les ordinacions de 1340, permet distingir
dues respostes al mateix problema de mobilitat ramadera: la regulació senyorial
del segle XIV i la concòrdia amb un capítol eclesiàstic del segle XVI.
