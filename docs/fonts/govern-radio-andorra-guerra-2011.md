# Govern d’Andorra — *L'incroyable aventure de Radio Andorra*

## Què aporta

El capítol sobre la guerra permet seguir una infraestructura situada a Andorra
que rebia pressions de tots els actors del conflicte. La font descriu la
seqüència, però no dona les ordres originals; per això el corpus en conserva el
valor de font institucional de síntesi.

## Reserves

La narració barreja fets, interpretacions i testimonis posteriors. Les
acusacions contra Jacques Trémoulet, Léon Laffont i Estanislau Puiggròs, així com
la condemna i l’absolució posterior, s’han de contrastar amb els expedients
judicials francesos. Les afirmacions sobre missatges per a les forces franceses
lliures provenen de testimonis d’evadits que la publicació resumeix.
