# Portal institucional del Consell General

El parlament d'Andorra publica al seu portal la composició, els òrgans, els
procediments, la Constitució, el Reglament i les publicacions oficials.

Per a qualsevol afirmació sobre com funciona el Consell, aquesta font té
prioritat sobre qualsevol font secundària: és la institució explicant-se.
