# Una concessió reial per obrir mercat a Andorra la Vella

La fitxa d’**Arxius en Línia** identifica l’ASC-1286 com el privilegi que la
reina **Caterina de Navarra** va atorgar el **20 de març de 1512** per celebrar
un mercat cada quinze dies a la vila d’Andorra la Vella.

El PDF és un escaneig de les dues cares d’un foli. La primera conté el document
manuscrit i la segona anotacions posteriors. La unitat no ofereix transcripció ni
traducció, de manera que aquesta font permet establir el concessionari, la
periodicitat i el lloc del mercat, però no les clàusules completes.
