# *Impacte de la immigració a Andorra* (2010)

La monografia coordinada per Maria Jesús Lluelles Larrosa estudia els fluxos
migratoris, els efectes socials i el sistema institucional de la immigració.
Per al corpus històric, el capítol de fluxos i el capítol de Ladislau Baró sobre
el sistema institucional permeten precisar la cronologia de 1929–1935 i
separar les polítiques de registre de les mesures d’ordre públic.
